# 타이니 아일 (Tiny Isle) — 게임 기획 문서

> 픽셀아트 아이소메트릭 디오라마 위에서 나만의 작은 왕국을 가꾸고, 밤마다 몰려오는 어둠의 무리로부터 지켜내는 **코지 경영 + 라이트 디펜스** 모바일 게임.

| 항목 | 내용 |
|---|---|
| 가칭 | 타이니 아일 (Tiny Isle) |
| 장르 | 정착지 경영 시뮬레이션 + 방치형 성장 + 라이트 디펜스 |
| 플랫폼 | iOS / Android (세로 화면) |
| 아트 스타일 | 아이소메트릭 픽셀아트 디오라마 (한 화면에 담기는 "손바닥 위의 섬") |
| 타겟 | 20~40대 캐주얼~미드코어, 코지 게임 선호층 (남녀 비율 균형) |
| 수익 모델 | **인앱결제(IAP) 전용, 광고 없음** — 시즌 패스 + 코스메틱 + 편의 상품 중심 |
| 벤치마크 | Kingdom Two Crowns, The Bonfire 2, 고양이와 스프(수익화), Pocket Build(감성) |

## 한 줄 요약

**"매일 10분, 나의 작은 섬이 자라나는 재미"** — 낮에는 수확·건설·낚시로 섬을 가꾸고, 밤에는 영웅들과 함께 섬을 지킨다. 유저는 광고 없이 쾌적하게 플레이하고, 결제는 "더 예쁘게, 더 편하게"를 원할 때 자연스럽게 일어난다.
