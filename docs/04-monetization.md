# 4. 수익화 및 경제 설계 — 광고 없는 IAP 모델

## 4.1 수익화 원칙

1. **광고 제로**: 배너·전면·보상형 광고 일절 없음. "광고 없는 쾌적함" 자체를 스토어 문구와 커뮤니티 셀링 포인트로 사용.
2. **Pay for Style & Convenience, not Power**: 결제는 ①꾸미기(코스메틱) ②시간 단축·편의 ③시즌 패스에 집중. PvP가 없으므로 P2W 논란 원천 차단.
3. **가챠 최소화(사실상 배제)**: 모든 상품은 내용물이 보이는 **정찰제 직접 구매**. 확률형은 무료 재화 상자에만 존재. → 2024년 시행 게임산업법 확률 공시 의무 리스크 회피 + 코지 유저층의 신뢰 확보.
4. **무과금 완주 가능**: 모든 게임플레이 콘텐츠(섬, 영웅, 주문)는 무과금 도달 가능. 과금은 "더 빨리, 더 예쁘게".

> 벤치마크: '고양이와 스프'가 증명한 모델 — 코지 장르에서 코스메틱+패스 중심 IAP로 광고 의존 없이도 장기 매출 가능 (한국/일본/미국에서 검증됨).

## 4.2 화폐 구조

| 화폐 | 획득 | 사용 | 비고 |
|---|---|---|---|
| 골드 🪙 (소프트) | 플레이 전반 | 건설, 훈련, 일반 상점 | 인플레 관리 대상 |
| 어둠의 정수 ✨ (플레이) | 밤 방어, 원정 | 영웅 승급, 섬 해금 | **구매 불가** — 능동 플레이 가치 보존 |
| 루멘 💎 (하드) | **IAP**, 업적, 패스 | 가속, 코스메틱, 편의 | 무료 수급은 월 소액 (구매 가치 유지) |
| 시즌 토큰 🎪 | 시즌 활동 | 시즌 한정 상점 | 시즌 종료 시 골드로 전환 |

## 4.3 상품 라인업

### A. 시즌 패스 — 매출의 척추 (예상 매출 비중 40%)
| 상품 | 가격 | 구성 |
|---|---|---|
| 등불 패스 (무료 트랙) | - | 기본 보상 라인 (구매 가치 미리보기 역할) |
| 등불 패스+ | ₩9,900 / 시즌(8주) | 프리미엄 트랙: 한정 건물 스킨 세트, 영웅 코스튬 1종, 루멘 800, 편의 버프 |
| 등불 패스++ | ₩19,900 | 위 + 즉시 10레벨 + 독점 섬 테마(하늘 배경) + 펫 1종 |

- 패스 경험치는 일일 의뢰·밤 방어로 자연 획득, **하루 30분이면 시즌 완주 가능한 완만한 곡선** (숙제화 방지).
- 시즌 종료 후 한정 스킨은 2시즌 뒤 일반 상점에 프리미엄 가격으로 복각 (FOMO 완화 + 후발 유저 매출).

### B. 월정액 — 안정 매출 (비중 20%)
| 상품 | 가격 | 구성 |
|---|---|---|
| 등불지기의 계약 | ₩4,900 / 30일 | 매일 루멘 100 (총 3,000 = 낱개 대비 250% 가치), 건설 대기열 +1, 오프라인 보상 캡 8→12시간 |

- 편의가 핵심이라 체감이 즉각적 → 갱신율 높음. 해지해도 게임플레이 불이익 없음(캡 원복일 뿐).

### C. 코스메틱 — 마진 최고 (비중 25%)
| 카테고리 | 가격대 | 예시 |
|---|---|---|
| 건물 스킨 세트 | ₩5,500~₩12,000 | "버섯 마을", "동방 정원", "고딕 성채" |
| 섬 테마 (지형+하늘+BGM) | ₩12,000~₩22,000 | "벚꽃비", "오로라의 밤", "여름 축제" |
| 영웅 코스튬 | ₩3,300~₩7,700 | 직업별 시즌 의상 |
| 펫/동물 | ₩3,300~₩5,500 | 섬을 돌아다니는 여우, 부엉이, 고양이 |
| 이펙트 | ₩2,200~₩4,400 | 수확 반짝임, 마법 색상, 발자국 |

- 디오라마 게임 특성상 **코스메틱이 화면 전체를 바꾼다** → 타 장르 대비 코스메틱 가치 체감이 큼. 스크린샷 공유 문화와 시너지.
- 미리보기 필수: 구매 전 자기 섬에 실시간 적용해보기 (전환율 핵심 장치).

### D. 루멘(하드 커런시) 팩 + 번들 (비중 15%)
| 상품 | 가격 |
|---|---|
| 루멘 팩 5티어 | ₩1,200 / ₩5,900 / ₩12,000 / ₩39,000 / ₩119,000 |
| **스타터 팩** (계정당 1회) | ₩2,900 — 루멘 300 + 건설 슬롯 +1(영구) + 한정 문패 (가치 400%) |
| 성장 팩 (섬 Lv 도달 시) | ₩5,900~₩12,000 — 마일스톤 축하 번들 |
| 시즌 축제 번들 | ₩9,900~₩22,000 — 시즌 이벤트 연계, 코스메틱+루멘 |

- 루멘 사용처: 건설/훈련 가속, 코스메틱 구매, 원정 재도전 티켓, 떠돌이 상인 새로고침.
- **스타터 팩이 첫 구매 장벽 돌파 장치**: 낮은 가격 + 영구 편의 포함 → 첫 결제 경험이 만족스러워야 이후 LTV가 열린다.

## 4.4 구매 전환 퍼널 설계

```
비과금 안착 (D1~D3)     →  가치 체감 (D3~D7)          →  첫 구매 (D7~D14)      →  반복 구매
광고 없음·무료 상자로       무료 패스 트랙에서              스타터 팩 ₩2,900         패스 갱신, 월정액,
"퍼주는 게임" 인상 형성     프리미엄 보상 미리보기            or 첫 코스메틱           시즌 코스메틱
```

- 결제 유도 팝업 금지. 상점 진입은 항상 유저 주도 (무료 등불 상자가 매일 상점 방문을 자연 유도).
- 첫 구매 전환율 목표 5%, 구매자 월 ARPPU 목표 ₩18,000.

## 4.5 인게임 경제 밸런스 (소스 & 싱크)

| 화폐 | 주요 소스 | 주요 싱크 | 인플레 방어 |
|---|---|---|---|
| 골드 | 방치 생산, 의뢰 | 건설비(레벨 지수 증가), 장식, 상인 | 후반 고가 장식·프레스티지 |
| 정수 | 밤 방어, 원정 | 영웅 승급, 섬 해금 | 승급 단가 상승 곡선 |
| 루멘 | IAP, 업적(월 ~300) | 가속, 코스메틱 | 무료 수급 상한 관리 |

- **가속 가격 공식**: 남은 시간 1시간 = 루멘 20 (선형, 구간 할인 없음 — 예측 가능성이 신뢰).
- 시즌마다 신규 골드 싱크(한정 장식 경매·대형 건축)를 투입해 고인물 자산 소각.

## 4.6 규제·플랫폼 준수 체크리스트

- [ ] 확률형 아이템 없음 → 무료 상자도 확률 전수 공시 (게임산업법 개정안 준수)
- [ ] 인앱 구매 항목 스토어 고지 (Apple/Google 정책)
- [ ] 미성년자 결제 한도 및 구매 확인 절차
- [ ] 청약철회/환불 정책 명시 (전자상거래법)
- [ ] 유료 재화 소멸 시점 고지 (루멘은 무기한, 시즌 토큰은 종료 시 전환 명시)
