# 6. 경제 밸런스 시트 v1

> 본 문서는 수치 설계의 **기준 공식과 대표 구간 샘플**을 정의한다. 전체 테이블은 스프레드시트로 관리하며 서버 Remote Config로 배포한다 (클라 하드코딩 금지).

## 6.1 시간 모델 (모든 수치의 기준 축)

| 항목 | 값 |
|---|---|
| 게임 내 1일 사이클 | 현실 20분 (낮 14분 + 밤 6분) |
| 밤 웨이브 발동 | 사이클 완료 후 **유저 접속 시** 시작, 최대 2회 대기 누적 |
| 오프라인 생산 캡 | 8시간 (월정액 시 12시간) |
| 목표 세션 | 8분 × 일 2.5회 |

## 6.2 자원 생산 (소스)

**기본 공식**: `분당 생산량 = 시설 기본생산 × 시설레벨 계수(1 + 0.25×(Lv-1)) × 배치 주민 수 × 영웅 버프`

| 시설 | 기본생산/분 (Lv1, 주민1) | 최대 주민 | 비고 |
|---|---|---|---|
| 밀밭 | 식량 4 | 2 | 수확 탭 시 20% 보너스 (능동 플레이 우대) |
| 낚시터 | 식량 3 + 물고기 도감 판정 | 1 | 희귀어는 골드 판매용 |
| 벌목장 | 목재 3 | 2 | |
| 채석장 | 석재 2 | 2 | 화톳불 Lv5에 해금 |
| 마나샘 | 마나 1.5 | 1 | 마나 보유 상한 100 (세션 소모형) |

**골드 소스**: 잉여 자원 판매(식량 10 = 골드 3), 일일 의뢰(150/일), 밤 방어(50~200/회), 원정.
**어둠의 정수 소스**: 밤 웨이브(3~10/회), 핏빛 달(30/주), 원정(주 평균 40). **구매·교환 불가.**

## 6.3 건설 비용 (싱크)

**비용 공식**: `업그레이드 비용 = 기초비용 × 1.35^(Lv-1)`, `건설 시간 = 기초시간 × 1.4^(Lv-1)`

대표 샘플 — 화톳불(섬 코어, 최대 Lv30):

| Lv | 목재 | 석재 | 건설 시간 | 해금 요소 |
|---|---|---|---|---|
| 1→2 | 50 | - | 2분 | 밀밭 2번째 |
| 4→5 | 172 | 60 | 8분 | 채석장, 방벽 |
| 9→10 | 1,006 | 350 | 1.2시간 | 마법탑, 원정 항구 |
| 14→15 | 4,545 | 1,580 | 6.4시간 | 두 번째 섬 해금 조건 |
| 19→20 | 20,548 | 7,143 | 21시간 | 세 번째 섬, 프레스티지 예고 |

**페이싱 검증 목표** (무과금, 일 20분 플레이 기준):
- D1 종료 시점: 화톳불 Lv3, 주민 4명
- D7: Lv9~10 (마법탑 해금 = 첫 주 마무리 보상 경험)
- D30: Lv15 + 두 번째 섬 진입 (첫 대형 마일스톤)
- D90: 세 번째 섬 (시즌 1 종료와 동기화)

가속 결제 체감: Lv15 구간 6.4시간 = 루멘 128 (약 ₩1,500 상당) — "기다려도 되고, 커피값이면 넘어갈 수 있는" 수준 유지.

## 6.4 밤 웨이브 난이도 곡선

**전투력 예산 공식**: `웨이브 전투력 = 40 × 1.18^(화톳불 Lv) × 요일 계수`

| 요소 | 값 |
|---|---|
| 일반 웨이브 | 예산의 100%, 몬스터 2~3종 조합 |
| 핏빛 달 (주 1회) | 예산의 220% + 보스 1 (기믹 전투) |
| 방어측 기대 전투력 | 웨이브 예산의 115~125% (평시 승률 ~90% 목표) |
| 패배 페널티 | 저장 자원의 10% 손실 + 주민 사기 -20% (30분 지속). 건물 파괴 없음 |

- 몬스터 단가: 스켈레톤 병사 10, 궁수 14, 늑대(빠름) 12, 스켈레톤 기사 35, 보스 150~400.
- 난이도는 **화톳불 레벨에만 연동** (영웅 전투력에 비연동) → "키울수록 쉬워지는" 정방향 보상 유지, 방치 유저 벽 방지.

## 6.5 영웅 성장 곡선

| 축 | 공식/값 | 병목 재화 |
|---|---|---|
| 레벨 (1~40) | 필요 XP = 100 × 1.22^(Lv-1), XP는 전투·시설 배치로 획득 | 시간 |
| 승급 (★1→★5) | 정수 30 / 80 / 200 / 500 | 어둠의 정수 (능동 플레이) |
| 특성 (Lv10/20/30) | 2택 1, 골드로 리스펙 가능 | 골드 |

- ★5 영웅 1명 완성 = 정수 810 ≈ 성실 플레이 6~8주 → **시즌 주기와 동기화** (시즌당 주력 영웅 1명 완성의 리듬).
- 영웅 전투력 상승은 웨이브 난이도에 반영되지 않으므로, 투자분은 **원정 깊이**에서 회수 (미드코어 동기).

## 6.6 루멘(하드 커런시) 흐름

| 방향 | 항목 | 월 규모 (활성 유저 기준) |
|---|---|---|
| 소스 (무료) | 업적 + 도감 마일스톤 + 시즌 무료 트랙 | ~300 |
| 소스 (유료) | IAP, 패스, 월정액 | 구매량 |
| 싱크 | 건설/훈련 가속 (시간당 20) | 주 소비처 |
| 싱크 | 코스메틱 (300~2,000) | 고가치 소비처 |
| 싱크 | 원정 재도전 티켓 (50), 상인 새로고침 (30) | 소액 반복 |

- 무료 수급 월 300 = 코스튬 1개를 2~3개월에 하나 (무과금도 꾸미기 경험 가능, 단 희소하게).
- **가속의 가치 앵커**: 루멘 100 ≈ ₩1,200 ≈ 5시간 단축. 모든 상품 가치는 이 앵커로 환산 검증.

## 6.7 오프라인 보상 계산

```
오프라인 보상 = Σ(시설 분당 생산 × 경과 분) × 0.8   (능동 플레이 프리미엄 20% 유지)
캡: 8시간 (월정액 12시간)
```

- 캡 도달 후 리포트에 "주민들이 쉬고 있어요" 표기 → 짜증이 아닌 세계관 언어로 캡 전달.
- 서버 타임스탬프 기준 정산 (클라 시계 조작 무효).

## 6.8 밸런스 검증 루틴

1. **시트 시뮬레이션**: 일 20분/60분/방치형 3개 페르소나 봇으로 D30 도달 곡선 자동 계산 → 목표 페이싱(6.3)과 ±15% 이내인지 확인.
2. **소프트론칭 실측**: 화톳불 레벨 분포 히스토그램을 주간 확인, 특정 레벨 정체(이탈 벽) 발견 시 해당 구간 비용 -10~20% 핫픽스.
3. **인플레 모니터링**: 골드 보유량 상위 5% 유저의 잔고 증가율 > 소비율이면 신규 골드 싱크 투입.
