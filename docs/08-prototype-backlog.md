# 8. Phase 0 프로토타입 백로그 (6주 / 3스프린트)

> 목표: **"낮 경영 + 밤 디펜스 루프가 재밌는가"**를 최저 비용으로 검증. 이 단계에서 만들지 않는 것을 지키는 게 핵심이다.

## 8.1 범위 원칙

**만든다**: 코어 루프 1회전의 전체 경험, 디오라마 카메라·밤낮 라이팅(감성 검증 대상), 기본 터치 조작감.
**만들지 않는다**: 서버(로컬 저장만), 결제, 소셜, 두 번째 섬, 도감, 시즌, 사운드(임시 에셋), 최종 아트(단 라이팅은 최종 품질).

## 8.2 스프린트 계획

### 스프린트 1 (주 1~2) — "섬이 돌아간다"
| # | 태스크 | 산출물 |
|---|---|---|
| S1-1 | 아이소메트릭 타일맵 + 고정 카메라 (2단계 줌) | 8×8 섬 렌더링 |
| S1-2 | 타일 탭 → 컨텍스트 액션바 UI 골격 | Build/Gather 동작 |
| S1-3 | 자원 3종(식량/목재/석재) + HUD | 자원 증감 |
| S1-4 | 건물 4종 배치·업그레이드 (밀밭, 오두막, 벌목장, 화톳불) | 건설 대기열 1칸 |
| S1-5 | 주민 스폰 + 시설 배치 + 자동 생산 루프 | 주민이 일하는 모습 |
| S1-6 | 밤낮 사이클 (20분) + 2D 라이팅 (화톳불·창문 불빛) | **감성 검증 1차** |

### 스프린트 2 (주 3~4) — "밤이 온다"
| # | 태스크 | 산출물 |
|---|---|---|
| S2-1 | 몬스터 스폰·경로 탐색 (섬 가장자리 → 화톳불) | 스켈레톤 1종 |
| S2-2 | 웨이브 시스템 (예산 공식 [06 §6.4](06-economy-balance.md)) | 난이도 스케일링 |
| S2-3 | 영웅 1명 (전사): 배치 지정 + 자동 전투 | 탭으로 위치 지정 |
| S2-4 | 방벽·화살탑 | 방어 건설 선택지 |
| S2-5 | 전투 결과 → 정수 보상 → 영웅 승급 1단계 | 능동 플레이 보상 고리 |
| S2-6 | 패배 처리 (자원 10% 손실 + 사기 디버프) | 실패해도 계속하고 싶은지 관찰 |

### 스프린트 3 (주 5~6) — "내일 또 하고 싶다"
| # | 태스크 | 산출물 |
|---|---|---|
| S3-1 | 오프라인 생산 + 부재중 리포트 화면 | 복귀 경험 |
| S3-2 | FTUE 초안 (첫 7분, [02 §2.9](02-core-gameplay.md)) | 강제 구간 최소화 |
| S3-3 | 낚시 원버튼 미니게임 | 세션 내 완급 조절 |
| S3-4 | 마법 1종 (성장 촉진) + 마나 게이지 | MAGIC 훅 검증 |
| S3-5 | 밸런스 시트 연동 (JSON 테이블 로드) | 수치 핫스왑 |
| S3-6 | 플레이테스트 빌드 + 설문·로그 계측 | 게이트 평가 자료 |

## 8.3 검증 게이트 (Phase 1 진입 조건)

외부/내부 테스터 10~15명, 3일간 자유 플레이:

| 질문 | 통과 기준 | 측정 |
|---|---|---|
| 루프가 재밌는가 | "내일 또 하고 싶다" 7/10+ | 설문 |
| 실제로 돌아오는가 | 자발적 재접속(D1) 60%+ | 로그 |
| 밤이 긴장되는가 | 밤 웨이브 "재밌었다" 7/10+ | 설문 |
| 감성이 전달되는가 | 스크린샷을 찍은 테스터 3+명 | 관찰 |
| 조작이 답답하지 않은가 | 조작 관련 불만 2건 이하 | 설문 |

**불통과 시**: 물량 추가 금지. 원인 축(경영 재미 vs 전투 재미 vs 페이싱)을 특정해 루프 자체를 재설계 후 2주 재검증.

## 8.4 프로토타입 기술 메모

- Unity 2D URP, 타일맵은 커스텀 아이소메트릭 소터 (Y-소트 + 높이 오프셋).
- 저장: 로컬 JSON + 서버 타임 대신 기기 시간 (프로토 한정 허용).
- 밸런스 값은 전부 `StreamingAssets/balance/*.json` — 기획자가 빌드 없이 수정.
- 아트 임시 규격이라도 [09 아트 가이드](09-art-style-guide.md)의 타일 그리드·팔레트 규칙은 준수 (재작업 방지).
