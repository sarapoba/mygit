# 5. 개발 로드맵 및 KPI

## 5.1 개발 마일스톤

### Phase 0 — 프로토타입 (6주)
**목표: "낮 경영 + 밤 디펜스" 코어 루프가 재밌는가?**
- 섬 1개 (8×8), 자원 3종(식량/목재/석재), 건물 6종
- 주민 자동 생산 + 밤 웨이브 (스켈레톤 1종) + 영웅 1명
- 플레이스홀더 아트 허용, 단 **디오라마 카메라·밤낮 라이팅은 이 단계에서 검증** (핵심 감성이므로)
- 게이트: 내부 테스트 10명 중 7명이 "내일 또 하고 싶다"

### Phase 1 — 버티컬 슬라이스 (8주)
**목표: 최종 품질 기준의 30분 경험**
- 최종 픽셀아트 파이프라인 확정 (타일·캐릭터·UI 스타일 가이드)
- FTUE(첫 7분) 완성, 영웅 3명, 마법 3종, 낚시 미니게임
- 오프라인 생산 + 부재중 리포트
- 게이트: 외부 테스터 D1 잔존 40%+

### Phase 2 — 소프트론칭 빌드 (12주)
**목표: 30일 콘텐츠 + 수익화 전 체계**
- 섬 2개, 영웅 8명, 도감 2종(물고기/동물), 원정 v1
- 시즌 패스 / 월정액 / 스타터 팩 / 코스메틱 상점
- 서버·계정·결제·분석 스택, 푸시 알림
- LiveOps 도구 (이벤트 스케줄러, 세그먼트 오퍼)

### Phase 3 — 소프트론칭 (8~12주, 제한 국가)
- 대상: 캐나다·호주·필리핀 등 표준 테스트 마켓 (한국 제외 — 본 시장 보호)
- **글로벌 출시 게이트**: D1 45% / D7 20% / D30 10% / 전환율 3% / 크래시율 <0.5%
- 미달 시 원인 지표별 반복 개선 (마케팅 지출 최소화 상태로)

### Phase 4 — 글로벌 출시 + 라이브
- 출시 시점: 시즌 1 "수확제의 계절" 동시 시작
- 이후 8주 시즌 사이클: 신규 섬(격시즌), 영웅 2명/시즌, 코스메틱 세트 2종/시즌
- 출시 +3개월: 길드(등대 연합), +6개월: 프레스티지("새 등불")

| 역할 | 인원 | 비고 |

## 5.3 기술 스택

| 영역 | 선택 | 이유 |
|---|---|---|
| 엔진 | **Unity 2D (URP)** | 2D 라이팅(밤낮·화톳불), 모바일 최적화, 인력 수급 |
| 서버 | Firebase (Auth/Firestore/RemoteConfig) → 성장 시 전용 서버 | 초기 비용 최소화, 소셜 1단계는 비동기라 충분 |
| 결제 | Unity IAP + 영수증 서버 검증 | 결제 어뷰징 방어 필수 (광고 없는 모델이라 결제 무결성이 생명) |
| 분석 | Firebase Analytics + Amplitude | 퍼널·리텐션 코호트 분석 |
| LiveOps | Remote Config 기반 이벤트/오퍼 스케줄링 | 클라 업데이트 없이 시즌 운영 |
| 크래시 | Crashlytics | |

- 데이터 설계 원칙: 경제 수치(생산량·가격·웨이브 난이도)는 전부 서버 테이블화 → 밸런스 패치를 앱 심사 없이 수행.
- 치트 방어: 오프라인 보상은 서버 타임스탬프 기준, 클라 시계 조작 무효화.

## 5.4 KPI 대시보드 (라이브 운영 상시 추적)

| 분류 | 지표 | 목표 |
|---|---|---|
| 리텐션 | D1 / D7 / D30 | 45% / 22% / 12% |
| 참여 | DAU/MAU, 평균 세션, 밤 웨이브 참여율 | 0.35+, 8분×2.5회, 70%+ |
| 수익 | 전환율, ARPPU, 패스 구매율, 월정액 갱신율 | 5%, ₩18,000, DAU 8%, 60%+ |
| 콘텐츠 | 시즌 패스 완주율, 원정 참여율, 도감 진행도 | 40% / 50% / 중앙값 30% |
| 품질 | 크래시율, 로딩 시간, 스토어 평점 | <0.5%, <5초, 4.5+ |
| 마케팅 | 오가닉 비율, 스크린샷 공유 수 | 공유 기능 사용률 주간 5% |

## 5.5 핵심 리스크와 대응

| 리스크 | 대응 |
|---|---|
| 코어 루프가 안 재밌음 (최대 리스크) | Phase 0 게이트 엄수 — 통과 못하면 루프 재설계, 물량 투입 금지 |
| 광고 없는 모델의 매출 하한 | 월정액+패스의 안정 매출 축 우선 검증, 소프트론칭 전환율 3% 게이트 |
| 콘텐츠 소진 이탈 | 시즌 파이프라인을 출시 전에 2시즌 분량 비축 |
| 유사 게임 카피 | 아트 감성·라이브 운영 속도가 해자 — 시스템만으론 못 베끼는 완성도 확보 |
| 확률형 규제 변화 | 애초에 가챠 배제 설계로 면역 |
