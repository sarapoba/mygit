# 3. 리텐션 설계 — "오래, 재밌게"

핵심 철학: **의무감이 아니라 애착으로 붙잡는다.** 코지 장르 유저는 숙제식 운영(놓치면 손해)에 민감하다. 손실회피 장치는 최소화하고, "돌아오면 반겨주는" 긍정 보상 구조로 설계한다.

## 3.1 시간 단위별 플레이 루프

### 일간 루프 (매일 접속 이유)
| 요소 | 내용 | 소요 |
|---|---|---|
| 부재중 섬 리포트 | 오프라인 생산 수령 (최대 8시간 누적 → 하루 2~3회 접속 유도) | 30초 |
| 밤 웨이브 | 접속 시 대기 중인 밤 방어 1~2회 | 3분 |
| 일일 의뢰 3종 | "밀 20 수확", "물고기 5마리" 등 자연 플레이로 완료 | 5분 |
| 떠돌이 상인 | 하루 1회 랜덤 교환 상점 (희귀 재료·장식 등장) | 30초 |
| 무료 등불 상자 | 매일 1회 무료 보상 (상점 방문 습관화) | 10초 |

- **연속 출석은 소프트하게**: 7일 누적형(끊겨도 리셋 없음, 누적 일수로 보상). 스트릭 붕괴 스트레스 제거.
- 일일 의뢰 미완료 페널티 없음. 완료 시 시즌 패스 경험치 지급으로 연결.

### 주간 루프 (주말 훅)
- **핏빛 달 보스 웨이브** (주 1회): 평소보다 강한 보스 + 확정 희귀 보상. 클리어 컷신급 연출.
- **원정 랭킹 시즌** (주 단위): 로그라이트 원정 최고 깊이 경쟁. 보상은 코스메틱 위주(경쟁 스트레스 완화).
- **주말 축제**: 금~일 생산량 버프 + 한정 장식 상인 등장.

### 월간/시즌 루프 (장기 목표)
- **시즌 (8주 단위)**: 테마 스토리 + 시즌 패스 + 한정 꾸미기 세트. 예: "수확제의 계절", "긴 밤의 축제", "벚꽃 섬".
- **신규 섬 해금**: 1~2개월 플레이 분량의 대형 목표. 새 테마·자원·영웅 동반.
- **도감 시스템**: 물고기(계절·날씨별 출현), 야생동물, 유물, 요리 도감. 수집률에 따른 영구 보상 → 완성 욕구.

## 3.2 심리 훅 매트릭스

| 심리 동기 | 대응 시스템 | 주의점 |
|---|---|---|
| 성장 확인 | 섬 발전도, 영웅 레벨, 부재중 리포트 | 수치 인플레 관리 |
| 수집 완성 | 도감 4종, 영웅 12+, 시즌 장식 세트 | "미획득 한정" 남발 금지 — FOMO는 시즌당 1세트만 |
| 자기표현 | 자유 배치, 스킨, 섬 테마 | 꾸미기 UI에 마찰 없어야 함 |
| 사회적 인정 | 섬 방문, 좋아요, 스크린샷 공유 | 비교 스트레스 없는 비경쟁 소셜 |
| 긴장/성취 | 밤 웨이브, 핏빛 달, 원정 | 실패 페널티는 가볍게 |
| 예측 기대 | "다음 밤까지 20분", 낚시 희귀어, 떠돌이 상인 | 확률 콘텐츠는 무료 재화로만 |

## 3.3 소셜 시스템 (2단계 도입)

**1단계 (출시 시점) — 비동기 소셜**
- 친구 섬 방문: 구경 + "등불 켜주기"(상호 소량 버프). 방문받은 흔적이 남는다.
- 스크린샷 모드: UI 숨김 + 시간대 필터(황혼/밤/눈) → SNS 공유 버튼. **공유가 곧 마케팅**.
- 선물: 하루 3회 친구에게 자원 선물 (수익 재화 제외).

**2단계 (출시 +3개월) — 길드 "등대 연합"**
- 5~20명 연합, 공동 목표(주간 어둠 정화 포인트) → 연합 한정 장식 보상.
- 연합 채팅은 스티커 중심(운영 리스크 최소화), 자유 채팅은 신고·필터 갖춘 후 오픈.

## 3.4 콘텐츠 소진 방어

방치+경영 장르 최대 이탈 사유는 "할 게 없어짐". 대응:

1. **시즌 파이프라인**: 8주마다 테마·패스·장식 갱신 (아트 중심이라 개발비 대비 효율 높음).
2. **절차 생성 원정**: 로그라이트 구조로 반복 플레이 자체가 콘텐츠.
3. **프레스티지 시스템 "새 등불"** (엔드게임): 본섬을 "완성"한 유저는 섬을 박물관으로 보존하고 새 섬을 상속 보너스와 함께 시작 → 고인물 재순환.
4. **밸런스 리듬**: 신규 병목 자원을 시즌마다 1종씩 순환 도입해 최적화 메타 갱신.

## 3.5 이탈 방지 및 복귀 설계

- **푸시 알림**: 맥락 기반 3종만 — ① 밤 웨이브 준비됨 ② 건설 완료 ③ 시즌 종료 D-3. 스팸 금지 (알림 끄기 = 이탈 신호).
- **복귀 유저 패키지**: 7일+ 미접속 후 복귀 시 "주민들이 기다렸어요" 연출 + 부재 기간 비례 보상 + 3일 부스트. 죄책감이 아닌 환대.
- **이탈 예측 대응**: 접속 간격 벌어지는 유저에게 원정 무료 티켓 등 능동 콘텐츠 오퍼 (LiveOps 세그먼트).
