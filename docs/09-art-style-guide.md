# 9. 아트 스타일 가이드 v1

> 레퍼런스: 업로드된 컨셉 이미지 (아이소메트릭 픽셀 디오라마, 밤하늘 배경, 돌+나무 UI). 이 문서는 외주·신규 아티스트가 합류해도 같은 그림이 나오게 하는 규격서다.

## 9.1 핵심 감성 키워드

**"따뜻한 불빛이 있는 작은 세계"** — 아늑함(cozy) 70% + 긴장(어둠의 위협) 30%. 귀엽되 유치하지 않게: 데포르메는 캐릭터에만, 환경은 반실사 비례.

## 9.2 기술 규격

| 항목 | 규격 |
|---|---|
| 투영 | 아이소메트릭 2:1 (26.57°), 디오라마는 정면 45° 회전 뷰 고정 |
| 지형 타일 | 64×32 px (베이스 그리드), 섬 측면 두께 96 px (흙+암반 단면) |
| 캐릭터 | 주민 24×36 px, 영웅 28×42 px (실루엣 우선 — 원거리에서 직업 식별 가능해야 함) |
| 건물 | 1×1(64×64)~2×2(128×128) 풋프린트, 지붕이 화면의 주인공 (탑뷰 비중 높음) |
| 렌더 배율 | 정수 스케일링만 (x2/x3), 앤티앨리어싱 금지 |
| 애니메이션 | 유닛 4~6프레임 (idle/walk/work/attack), 환경 루프 8프레임 (강물, 밀 흔들림) |

## 9.3 팔레트 운영

- **마스터 팔레트 48색** 고정 (환경 32 + 캐릭터/UI 16). 신규 에셋은 팔레트 외 색 사용 금지.
- **밤낮 전환은 에셋 교체가 아닌 팔레트 시프트 셰이더**: 낮 → 황혼 → 밤 3단계 LUT. 밤에는 채도 -40%, 남색 틴트 + 발광 오브젝트(창문, 화톳불, 마법)만 원색 유지 → 레퍼런스의 "밤에 빛나는 섬" 감성.
- 시즌 테마( [07](07-season1-content.md) )는 환경 32색 중 식생 계열 12색만 스왑해 구현 → 저비용 대규모 분위기 전환.

## 9.4 발광(Emission) 규칙 — 이 게임의 시그니처

| 소스 | 색 온도 | 용도 |
|---|---|---|
| 화톳불·창문 | 따뜻한 주황 (2700K 느낌) | 안전, 집, 지켜야 할 것 |
| 마법 | 청백/보라 | 플레이어의 힘 |
| 몬스터 눈·안개 | 차가운 청록 | 위협 (주황과 보색 대비) |

밤 장면의 감정 전달은 전적으로 이 대비에 의존한다. 스크린샷 모드 기본 프리셋도 "황혼+창문 불빛".

## 9.5 UI 스타일

- 재질: 돌 프레임 + 나무 패널 + 금속 리벳 (레퍼런스 하단 바 계승). 9-slice 제작.
- 아이콘: 32×32 px, 두꺼운 외곽선 1px 다크브라운, 픽셀 그리드 정렬 필수.
- 폰트: 픽셀 폰트는 **한글 가독성 우선** (둥근모 계열 커스텀), 숫자는 별도 굵은 세트.
- 모션: UI 등장은 2~3프레임 스텝 애니메이션 (트윈 금지 — 픽셀 감성 유지), 햅틱과 동기화.

## 9.6 코스메틱 제작 규칙 (수익 상품의 품질 기준)

1. 스킨은 실루엣 변경 가능, **풋프린트·기능 판독성은 불변** (밀밭 스킨도 "밭"으로 읽혀야 함).
2. 섬 테마는 하늘 그라디언트 + 팔레트 LUT + 앰비언트 파티클(벚꽃, 눈, 반딧불) + BGM 1트랙 세트로 구성.
3. 유료 코스메틱은 **발광 요소를 1개 이상 포함** (밤 스크린샷에서 티가 나야 공유 욕구 → 오가닉 마케팅).
4. 모든 코스메틱은 밤낮 LUT 3단계에서 검수 후 출시.

## 9.7 목업 제작 계획 (Phase 1 산출물)

1. **낮 목업**: 본섬 풀 발전 상태 (스토어 스크린샷 1번 후보)
2. **밤 목업**: 핏빛 달 웨이브 전투 (긴장감 전달)
3. **겨울 테마 목업**: 시즌 2 "서리안개" 프리뷰 (라이브 운영 비주얼 검증)

각 목업은 4K 원본 + 스토어 규격 + SNS 규격 3종 출력.
