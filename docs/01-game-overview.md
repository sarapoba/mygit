# 1. 게임 개요 및 컨셉

## 1.1 컨셉 정의

**"손바닥 위의 살아있는 디오라마"**

레퍼런스 이미지의 핵심 매력을 그대로 가져간다:

- 한 화면에 온전히 담기는 **아이소메트릭 픽셀아트 섬 타일** — 밀밭, 초가집, 강, 전나무 숲, 토끼가 뛰노는 풍경
- 섬 위에서 **각자 일하는 주민들** — 밀을 수확하는 농부, 강에서 낚시하는 어부, 나무를 베는 나무꾼
- 평화로운 낮과 대비되는 **밤의 위협** — 강 건너에서 다가오는 스켈레톤 무리
- 좌측 메뉴(BUILD / HEROES / MAGIC / MAP)와 하단 액션바(Build / Train / Gather / Fish / Attack)로 이루어진 직관적 조작

여기에 **장기 성장 축(섬 확장, 영웅 수집·육성, 시즌 콘텐츠)** 을 더해 "보는 재미"를 "키우는 재미"로 연결한다.

## 1.2 핵심 재미 (Core Fun) — 3개의 기둥

| 기둥 | 설명 | 감정 |
|---|---|---|
| **가꾸기 (Nurture)** | 빈 섬에 밭을 갈고, 집을 짓고, 주민을 늘린다. 방치 중에도 주민들이 일해서 돌아올 때마다 섬이 자라 있다 | 애착, 뿌듯함 |
| **지키기 (Defend)** | 밤이 되면 몬스터 웨이브가 온다. 낮 동안 준비한 방벽·영웅·마법으로 막아낸다 | 긴장, 성취 |
| **꾸미기 (Express)** | 건물 스킨, 섬 테마, 동물, 장식으로 나만의 디오라마를 완성하고 친구에게 자랑한다 | 자기표현, 과시 |

세 기둥이 각각 **방치형 리텐션(가꾸기) → 세션 몰입(지키기) → 수익화(꾸미기)** 를 담당한다.

## 1.3 세계관 (Narrative Frame)

- 대재앙 "긴 밤(The Long Night)" 이후, 세계는 어둠의 안개에 잠기고 작은 섬들만 빛의 결계 속에 남았다.
- 플레이어는 마지막 **등불지기(Lightkeeper)** — 섬의 화톳불을 지키며 흩어진 생존자(영웅)를 모으고, 안개 너머의 섬들을 하나씩 되찾는다.
- 섬을 밝힐수록 지도(MAP)의 안개가 걷히며 새로운 지형·영웅·이야기가 열린다. → **"안개 걷기" 자체가 장기 콘텐츠 로드맵의 서사적 그릇**이 된다.

스토리는 가볍게: 컷신 없이 영웅 대사·유물 설명·섬 해금 텍스트로 조각조각 전달 (코지 게임 톤 유지).

## 1.4 아트 디렉션

- **픽셀아트, 아이소메트릭 45°, 디오라마 프레이밍**: 섬 전체가 항상 한 화면에 들어오도록 카메라 고정 + 2단계 줌만 허용. "미니어처를 들여다보는" 감각이 최우선.
- **밤낮 사이클과 라이팅**: 레퍼런스처럼 짙은 남색 밤하늘 배경. 밤에는 창문 불빛·화톳불·마법 이펙트가 돋보이도록 설계 → 스크린샷 공유 욕구 자극.
- **살아있는 디테일**: 토끼·닭·새 등 야생동물, 흔들리는 밀, 흐르는 강. 기능이 없어도 "보고 있게 만드는" 요소에 리소스를 아끼지 않는다.
- **UI**: 돌+나무 질감의 픽셀 UI (레퍼런스 하단 바 스타일). 팝업 최소화, 화면을 가리지 않는 것이 원칙.

## 1.5 벤치마크 분석

| 게임 | 배울 점 | 피할 점 |
|---|---|---|
| **Kingdom Two Crowns** | 낮(준비)/밤(방어) 사이클의 긴장감, 미니멀 조작 | 불친절한 튜토리얼, 모바일 리텐션 장치 부재 |
| **The Bonfire 2** | 주민 배치·성장의 디오라마 경영 재미 | 유료 프리미엄 모델(우리는 F2P), 콘텐츠 소진 후 이탈 |
| **고양이와 스프** | 코지 감성 + 광고 없는 유저도 존중하는 UX, 스킨/가구 IAP로 높은 매출, 방치 보상 설계 | 후반 콘텐츠 단조로움 |
| **Pocket Build** | 자유 꾸미기의 만족감 | 목표 부재로 인한 조기 이탈 |
| **AFK 아레나 류** | 방치 보상·영웅 수집의 성장 동기 | 과도한 가챠 의존 (우리는 가챠 최소화) |

**포지셔닝**: "Kingdom의 낮/밤 긴장감 × 고양이와 스프의 코지 수익화" — 이 조합이 비어 있는 시장.

## 1.6 타겟 유저 페르소나

1. **코지 게이머 (주 타겟)**: 25~39세, 출퇴근·자기 전 10~20분 플레이. 광고에 피로감이 크고, 마음에 드는 게임엔 월 5천~2만원 지출 의향. 꾸미기·수집에 반응.
2. **라이트 전략 게이머 (부 타겟)**: 디펜스·성장 최적화를 즐김. 영웅 조합, 웨이브 공략, 원정 랭킹이 훅.
3. **감상형 유저**: 게임을 "예쁜 인터랙티브 화면"으로 소비. 스크린샷 공유가 오가닉 마케팅 채널이 된다.

## 1.7 차별화 포인트 요약

1. 한 화면 디오라마 + 밤낮 사이클 = **스크린샷만으로 전달되는 게임성** (마케팅 효율)
2. 광고 제로 정책 = 코지 장르 유저의 최대 불만 해소, 그 자체가 셀링 포인트
3. 방치형의 접근성 + 디펜스의 능동적 재미 = 짧은 세션과 깊은 세션 모두 지원
4. 가챠 없는 정찰제 수익화 = 신뢰 기반 장기 과금 (자세한 근거는 [04 수익화](04-monetization.md))
