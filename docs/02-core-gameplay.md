# 2. 코어 게임플레이

## 2.1 코어 루프 (1세션 = 5~15분)

```
        낮 (준비 페이즈)                          밤 (방어 페이즈)
┌─────────────────────────────┐        ┌──────────────────────────┐
│ 수확/채집/낚시 → 자원 획득      │        │ 몬스터 웨이브 접근            │
│ 자원 → 건설(밭·집·방벽·작업장)  │  ───→  │ 영웅 배치 + 마법 사용         │
│ 자원 → 주민 훈련(영웅 성장)     │        │ 방어 성공 → 전리품·정수 획득    │
└─────────────────────────────┘        └──────────────────────────┘
        ↑                                          │
        └────────── 보상으로 섬 확장·해금 ←───────────┘
```

- **낮**: 하단 액션바(Build / Train / Gather / Fish / Attack)로 섬을 운영. 주민에게 일을 할당하면 방치 중에도 자동 생산.
- **밤**: 실시간으로 진행되는 짧은(60~90초) 웨이브 디펜스. 유저는 영웅 위치 지정 + 마법 시전만 담당하는 **라이트 조작** (자동전투 토글 지원).
- **하루 사이클 = 현실 시간 약 20분** (오프라인에서도 진행되지만, 밤 웨이브는 유저 접속 시에만 발동 → "밤이 기다리고 있어요" 복귀 훅).

## 2.2 자원 시스템

| 자원 | 획득처 | 용도 | 성격 |
|---|---|---|---|
| 식량 🌾 | 밀밭 수확, 낚시 | 주민 유지, 훈련 | 기본 순환 자원 |
| 목재 🪵 | 벌목 | 건설 | 기본 순환 자원 |
| 석재 ⛏ | 채석 (Gather) | 상위 건설, 방벽 | 중반 병목 자원 |
| 마나 💧 | 마나샘, 밤 방어 보상 | 마법(MAGIC) 시전 | 세션 내 소모 자원 (레퍼런스의 파란 게이지) |
| 어둠의 정수 ✨ | 밤 웨이브 클리어 | 영웅 승급, 섬 해금 | 능동 플레이 보상 자원 |
| 골드 🪙 | 판매, 퀘스트, 방치 보상 | 범용 소프트 커런시 | 경제 허브 |
| 루멘 💎 | **IAP**, 시즌패스, 업적 | 프리미엄 화폐 | 하드 커런시 ([04 참조](04-monetization.md)) |

설계 원칙: **능동 플레이(밤 방어) 전용 자원(어둠의 정수)을 성장의 핵심 병목으로** 두어, 방치만으로는 완성되지 않고 세션 접속의 이유를 만든다.

## 2.3 건설 시스템 (BUILD)

- 섬은 **격자 타일** 기반. 초기 섬은 8×8 상당, 확장으로 최대 12×12까지.
- 건물 카테고리:
  - **생산**: 밀밭, 낚시터, 벌목장, 채석장, 마나샘 — 주민 배치 시 자동 생산
  - **주거**: 오두막 → 가옥 → 저택 (주민 수 상한 증가)
  - **군사**: 방벽, 화살탑, 훈련소, 화톳불(섬의 코어 — 파괴 시 밤 방어 실패)
  - **특수**: 마법탑(주문 해금), 항구(원정 출항), 창고(자원 상한)
  - **장식**: 기능 없음, 순수 꾸미기 + 소량의 "아늑함" 버프 (코스메틱 수익화 연결점)
- 건설은 **대기열 1칸 + 시간 기반** (분 단위 → 후반 시간 단위). 대기열 추가 슬롯은 영구 편의 상품.
- **건물 배치 자유도**가 핵심: 같은 건물도 배치에 따라 디오라마가 달라진다 → 자기표현.

## 2.4 영웅 시스템 (HEROES)

- 주민(제네릭 일꾼)과 별개로, 이름·성격·스킬을 가진 **영웅**을 수집·육성.
- 영웅 직업: 전사(근접 방어), 궁수(원거리), 마법사(광역), 농부(생산 버프), 어부(낚시 특화), 사제(회복) 등 출시 시점 12명.
- **획득 경로 (가챠 없음)**:
  - 스토리/섬 해금 보상 (핵심 영웅)
  - 원정 콘텐츠의 "표류자 구조" (플레이로 확정 획득)
  - 시즌 패스 보상, 코스튬은 상점 직접 구매
- 성장: 레벨(경험치) → 승급(어둠의 정수) → 특성 선택(빌드 다양성). **영웅 자체는 무과금 획득 가능, 과금은 성장 가속과 코스튬**이 원칙.
- 영웅은 낮에는 생산 보조(배치한 시설 버프), 밤에는 전투 참여 → 하나의 캐릭터가 두 루프를 잇는다.

## 2.5 전투 시스템 (밤 디펜스 + Attack)

- **밤 웨이브**: 섬 가장자리(강 건너, 마른 나무 쪽 등)에서 스켈레톤 등 몬스터가 화톳불을 향해 진행. 방벽·탑·영웅으로 저지.
  - 웨이브 난이도는 섬 발전도에 비례 + 7일마다 **"핏빛 달"** 보스 웨이브 (주간 이벤트 훅).
  - 실패해도 파괴가 아닌 **"주민 사기 저하 + 일부 자원 손실"** — 코지 톤 유지, 과도한 손실회피 스트레스 배제.
- **Attack (능동 공격)**: 섬 주변 안개 지역의 몬스터 둥지를 선제 공격해 정수·희귀 재료 획득. 스태미나(하트, 레퍼런스의 빨간 게이지) 소모형 → 세션 길이 자연 제한.

## 2.6 마법 시스템 (MAGIC)

- 마나를 소모하는 **즉발 주문**: 성장 촉진(밭 즉시 수확), 낙뢰(전투), 회복의 빛, 시간의 모래(생산 가속) 등.
- 주문은 마법탑 레벨로 해금, **쿨다운 없이 마나로만 제한** → 마나 관리가 곧 전략.
- 시즌마다 신규 주문 1~2종 추가 (라이브 콘텐츠 축).

## 2.7 탐험과 확장 (MAP)

- 미니맵(레퍼런스 우상단)은 **군도(群島) 지도**: 안개에 덮인 이웃 섬들이 보인다.
- **섬 해금 (월 단위 장기 목표)**: 본섬 발전 + 어둠의 정수로 새 섬 해방. 새 섬은 테마(설원, 사막, 늪지, 화산)와 고유 자원·몬스터·영웅을 가진다. 유저는 섬들을 오가며 **연방 경영**.
- **원정 (주 단위 반복 콘텐츠)**: 항구에서 영웅 파티를 꾸려 로그라이트 원정(3~5스테이지, 10분 내외). 깊이 기록으로 주간 랭킹 → 미드코어 유저 훅.

## 2.8 UI/UX 설계 (레퍼런스 화면 구조 계승)

```
┌──────────────────────────────┐
│ [BUILD]                [미니맵] │  ← 좌: 글로벌 메뉴 (세로 버튼 스택)
│ [HEROES]                      │     우상단: 군도 미니맵 (탭하면 MAP)
│ [MAGIC]                       │
│ [MAP]        ◇ 섬 디오라마 ◇    │  ← 중앙: 항상 섬 전체가 보이는 고정 카메라
│ [SETTINGS]                    │
│                               │
│  [❤HP게이지]      [💧마나게이지]  │  ← 하단 상태바
│ [Build][Train][Gather][Fish][Attack] │ ← 컨텍스트 액션바 (선택 대상에 따라 변화)
└──────────────────────────────┘
```

- **원탭 원칙**: 모든 핵심 행동은 "대상 탭 → 액션바 탭" 2터치 이내.
- **팝업 최소화**: 상점·인벤토리 외에는 전체화면 팝업 금지. 디오라마가 항상 보여야 한다.
- **오프라인 복귀 화면**: 접속 시 "부재중 섬 리포트" (생산량 + 밤 웨이브 대기 알림 + 주민들의 한 마디) — 복귀 순간을 보상 경험으로.
- 세로 화면 고정 (한 손 플레이), 햅틱 피드백으로 수확·타격 손맛 강화.

## 2.9 신규 유저 경험 (FTUE, 첫 7분)

1. (0~1분) 폐허가 된 섬 + 꺼져가는 화톳불 → 불 붙이기 (원탭)
2. (1~3분) 밀밭 수확 → 첫 건설(오두막) → 주민 1명 합류
3. (3~5분) 첫 밤: 스켈레톤 2마리 → 전사 영웅이 등장해 구해줌 (영웅 시스템 소개)
4. (5~7분) 낚시 미니게임 → 지도에서 안개 걷히는 연출 → "다음 밤까지 20분" 타이머 노출
5. 첫 세션 종료 유도 지점에서 **푸시 알림 수락 요청** ("밤이 오면 알려드릴게요" — 맥락 있는 권한 요청)

튜토리얼 완료율 목표: 85% 이상. 강제 진행은 첫 밤까지만, 이후 자유.
