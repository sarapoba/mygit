> 표기: 존은 위→아래 순서. `[P0]`/`[P1]`/`[P2]` = 등장 Phase. 목업 → [prototype/index.html](prototype/index.html).

## 1. 온보딩 ON-00 (S01~S14) — 비주얼 패턴 4종

카피·분기·상태 머신은 07 문서가 전부. 여기서는 14개 스텝을 4개 레이아웃 패턴으로 수렴시킨다(개발 효율 + 리듬감).

| 패턴 | 적용 스텝 | 존 구성 |
|---|---|---|
| A. 풀블리드 스테이지 | S01 웰컴, S05 분석, S10 보상, S14 랜딩 | ① 상단 60% 일러스트 스테이지(P0: 새싹 심벌 / P1: 루티) ② 헤드라인 `display` ③ 서브 카피 1줄 ④ 하단 고정 1차 버튼 (S05는 버튼 없음—자동 전진) |
| B. 질문 카드 | S02~S04 진단 | ① 진행 도트 3개(상단 중앙) ② 질문 `title-1` ③ 선택지 카드 3~4장 세로 스택(높이 72, 이모지+라벨+서브카피, 탭 즉시 전진 — 확인 버튼 없음) ④ 하단 좌측 "뒤로" 텍스트 버튼 |
| C. 제안 카드 | S06 추천, S07 확정, S08 축소 | ① 컨텍스트 라벨(caption, 예: "저녁형 × 몸") ② 메인 제안 카드 1장(루틴명 `title-2`+구성 습관+검증 카피) ③ 대안 카드 2장(축소 스케일 80%) ④ 하단 1차 버튼 + 보조 텍스트 링크 |
| D. 액션 스테이지 | S09 첫 체크, S11 알림, S13 위젯 | ① 헤드라인 ② 인터랙티브 요소 1개(72pt 체크 버튼 / 시각 피커 / 위젯 프리뷰 목업) ③ 하단 1차 버튼 + "나중에" 링크 |

디자인 노트: 온보딩 전체 배경은 `paper` 단색 — 첫 3분은 장식보다 속도(07 §1). S12(OS 다이얼로그)는 자체 UI 없음.
