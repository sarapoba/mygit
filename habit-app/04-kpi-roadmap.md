# 04. KPI 및 실행 로드맵

## 1. 단계별 로드맵

### Phase 0 — 검증 (2개월)
- **범위**: 프로토타입 — 온보딩(진단→루틴 추천→극소 습관→첫 체크), 습관 3개 트래킹, 스트릭+프리즈, 기본 위젯.
- **제외**: AI 코치, 소셜, 결제 전부. 리텐션 코어 루프만 검증한다.
- **검증 게이트**: 베타 코호트 D7 ≥ 15%, 첫 주 체크인 완료율 ≥ 50%. 미달 시 온보딩·루프부터 재설계 (수익화 진입 금지).

### Phase 1 — 구독 출시 (3~4개월)
- **범위**: 캐릭터(애착 대상) v1, AI 코치 v1(일일 브리핑·미루기 개입), 루틴 라이브러리 50종, 주간 리포트, 소프트 페이월 + 7일 체험, 구독 결제.
- **검증 게이트**: 체험→유료 ≥ 25%, D30 ≥ 8%, 페이월 결함 0건(크래시·가격 로딩 실패 — Pillar 반면교사).

### Phase 2 — 차별화 (출시 후 3~6개월)
- **범위**: 보증금 챌린지(법무 검토 선행), 소그룹 챌린지, 코스메틱 상점, 시즌 캠페인 1회차.
- **검증 게이트**: 챌린지 참가자 D30이 비참가자 대비 +10%p 이상, 챌린지 완주율 ≥ 60%(완주율이 낮으면 몰수 수익은 늘어도 평판과 재참가가 죽는다 — **완주율을 수익보다 우선**).

### Phase 3 — 확장 (출시 후 6~12개월)
- 책임 파트너 매칭 실험, B2B 웰니스 파일럿, 커머스 제휴 검토, 글로벌(영어권) 현지화.

## 2. 북극성 지표와 지표 트리

**북극성: 주간 체크인 완료 유저 수 (WCU, Weekly Check-in Users)**
— MAU보다 행동 기반이며, 유저 가치("습관이 실제로 굴러감")와 사업 가치(전환·유지의 선행지표)를 동시에 대변.

```
WCU
├─ 신규: 설치 → 온보딩 완료율 → 첫 체크 경험률 (D1 45%)
├─ 유지: 스트릭 7일+ 도달률 (35%) → 용서 장치 사용률 → 복귀율 (55%)
└─ 수익: 체험 시작률 (9%) → 체험→유료 (35%) → 12개월 유지 (40%)
```

## 3. 최우선 실험 백로그 (출시 첫 분기)

| # | 실험 | 가설 | 판정 지표 |
|---|---|---|---|
| 1 | 용서 장치 on/off | 프리즈+회복 체크가 D30을 +5%p 올린다 | D30, 복귀율 |
| 2 | 캐릭터 유무 | 애착 대상이 D7~D30 유지와 코스메틱 매출을 만든다 | D30, 세션 빈도 |
| 3 | 페이월 타이밍 3종 | "3일 스트릭 직후"가 온보딩 직후 대비 체험 시작률을 올린다 | 체험 시작률, D7 |
| 4 | 극소 습관 강제 축소 | 2분 버전 제안이 첫 주 완료율을 +10%p 올린다 | 첫 주 체크인 완료율 |
| 5 | 연간 우선 vs 월간 우선 페이월 | 연간 우선이 LTV를 올린다 | ARPU, 체험→유료 |

## 4. 리스크 레지스터

| 리스크 | 영향 | 대응 |
|---|---|---|
| 보증금 모델 법적 이슈 (사행성·전자금융) | Phase 2 지연 | 법무 검토를 Phase 1 중에 선행, 챌린저스 선례 분석. 불가 시 "가상 보증금(재화)" 폴백 |
| AI 추론 원가 > 구독 매출 | 마진 붕괴 | AI 무제한은 구독 전용, 무료는 주 1회 배치. 모델 티어링(경량 모델 기본) |
| 알림 의존 리텐션의 취약성 (OS 정책 변화) | 계기 상실 | 위젯·잠금화면 등 OS 표면 다변화를 Phase 0부터 필수로 |
| 신년 코호트 대량 이탈 | 지표 왜곡 | 시즌 코호트 분리 측정, 시즌 전용 온보딩·챌린지로 흡수 |
| 카피캣 (기능 모방) | 차별화 상실 | 기능이 아닌 축적 자산(캐릭터 애착, 데이터 인사이트, 친구 그래프)으로 해자 구축 |

## 5. 한 장 요약

> **무료로도 완결된 습관 루프**(습관 3개 + 스트릭 + 용서 장치)로 평판과 오가닉을 얻고,
> **"잃기 싫은 것이 생긴 순간"에 소프트 페이월**로 구독 전환하며,
> **돈을 걸면 AI 코치가 붙는 보증금 챌린지**로 차별화한다.
> 리텐션의 핵심은 완벽주의 붕괴를 막는 **용서 장치**와, 시간이 갈수록 커지는 **애착 자산**(스트릭·캐릭터·데이터·친구)이다.
