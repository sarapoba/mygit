## 확정된 제품 방향 (변경 시 하위 문서 전부 영향)

- **제품**: 루트(ROOT) — "하루 2분, 끊기지 않는 습관". 캐릭터 루티(새싹→나무), 톤은 "혼내는 코치 말고 같이 자라는 존재"
- **수익화 3단 하이브리드**: 소프트 페이월 구독(코어) + 보증금 챌린지(차별화) + 코스메틱(보완)
  - 가격: 월 6,900 / 연 39,000(주력, 7일 체험) / 프리즈 단품 1,100
  - Pillar의 하드 페이월은 **반면교사** — 무료로도 코어 루프가 완결되어야 평점·오가닉이 산다
- **리텐션 핵심**: `하루 놓침 → 완벽주의 붕괴 → 이탈` 경로를 용서 장치로 차단
  - 프리즈(자동 소모) + "한 번은 사고" 회복 체크(월 1회) + 부분 달성(2분 버전) 동일 인정
- **하루 경계는 자정이 아닌 로컬 04:00** (새벽 체크의 억울한 끊김 방지)
- **Phase 0 범위**: 온보딩·습관 3개·스트릭/프리즈·위젯만. AI·소셜·결제 없음. 게이트 = 베타 D7 ≥ 15%
- **디자인**: 빨강은 시스템 에러 전용 / 모티프는 식물(잎·눈송이·이슬) / 다크는 "밤의 정원"(반전 아닌 전용 팔레트)
