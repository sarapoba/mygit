# 습관 형성 자기계발 앱 (가칭: 루트, ROOT) — 수익화·리텐션 기획서

> Pillar류 자기계발 습관 앱의 **수익화 전략 분석**과 **장기 리텐션 설계**를 다루는 기획 문서 세트.
> "습관을 만들어주는 앱"은 곧 "앱 사용 자체가 습관이 되어야 하는 앱"이다 — 리텐션 설계와 제품 본질이 일치하는 드문 카테고리이며, 이 정합성이 본 기획의 출발점이다.

| 항목 | 내용 |
|---|---|
| 가칭 | 루트 (ROOT) — "뿌리내리다 + 매일의 경로(route)" 중의적 의미 |
| 카테고리 | 습관 형성 / 자기계발 / 웰니스 |
| 플랫폼 | iOS / Android (세로 화면), 홈 위젯 필수 |
| 타겟 | 1차: 20~35세 자기계발 관심층 (학생·주니어 직장인), 2차: 35~45세 루틴 관리층 |
| 수익 모델 | **프리미엄 구독(코어) + 챌린지 보증금(차별화) + 코스메틱(보완)** 하이브리드 |
| 벤치마크 | Pillar(AI 코칭·하드 페이월), Duolingo(스트릭), Finch(정서 애착), 챌린저스(보증금), Fabulous(온보딩) |

## 핵심 결론 요약

**수익화**: 하드 페이월(Pillar 방식)은 ARPU는 높지만 설치→가입 전환을 크게 깎고 스토어 평판을 훼손한다(Pillar 실제 리뷰에서 확인). 권장안은 **소프트 페이월 프리미엄 구독**을 코어로 하되, 한국 시장에서 검증된 **챌린지 보증금 모델(챌린저스식)** 을 차별화 축으로 결합하는 것. 보증금 모델은 수익원이면서 동시에 그 자체가 최강의 리텐션 장치(손실 회피)라는 점에서 이 카테고리와 정합성이 가장 높다.

**리텐션**: 습관 앱 이탈의 최대 원인은 "하루 놓침 → 완벽주의 붕괴 → 포기"의 연쇄다. 따라서 스트릭(연속 달성)만큼 **용서 장치(스트릭 프리즈, 부분 달성 인정)** 가 중요하다. 온보딩 첫 3분 안에 "첫 습관 1개 체크" 경험을 만들고, 이후는 Hook 모델(계기→행동→가변 보상→투자)로 일·주·월 루프를 겹겹이 쌓는다.
