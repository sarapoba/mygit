## 2. 권장 모델: 3단 하이브리드

```
[코어]   프리미엄 구독  ──  예측 가능한 기본 매출 (전체 매출의 60~70% 목표)
[차별화] 챌린지 보증금  ──  손실 회피 리텐션 + 수수료 매출 (20~30%)
[보완]   코스메틱 IAP   ──  애착 기반 추가 매출 (5~10%)
```

세 축이 서로를 강화한다: 구독자는 챌린지 수수료 할인·프리즈 추가 지급을 받고(구독 가치 상승), 챌린지 성공 보상으로 코스메틱 재화를 지급하며(챌린지 참여 동기), 코스메틱으로 꾸민 애착 대상이 이탈 비용을 높인다(구독 유지).

### 2.1 무료 / 유료 경계 설계 (소프트 페이월)

**원칙: 코어 습관 루프는 영원히 무료. 유료는 "더 많이·더 깊게·더 편하게".**
무료 티어가 온전히 작동해야 스토어 평점·오가닉 유입·소셜 네트워크 효과(친구 초대)가 산다. Pillar의 실패를 뒤집는 지점.

| 기능 | 무료 | 프리미엄 |
|---|---|---|
| 습관 개수 | 3개 | 무제한 |
| 스트릭 + 기본 캘린더 | ✅ | ✅ |
| 스트릭 프리즈 | 월 1개 | 월 4개 + 광고 시청으로 추가 획득 |
| 루틴 라이브러리 (성공인 루틴) | 미리보기 + 무료 5종 | 전체 150+ |
| AI 코치 (일일 브리핑·미루기 개입) | 주 1회 요약만 | 매일 무제한 |
| 통계·인사이트 (주간 리포트, 상관 분석) | 기본 잔디밭 | 심화 리포트 |
| 챌린지 참가 수수료 | 기본 수수료 | 수수료 50% 할인 |
| 위젯 | 기본 1종 | 전체 테마 |

### 2.2 가격 설계

| 상품 | 가격(₩) | 비고 |
|---|---|---|
| 월간 구독 | 6,900 | 앵커 역할 — 연간을 돋보이게 하는 기준가 |
| **연간 구독 (주력)** | 39,000 (월 3,250 꼴) | "월간 대비 53% 할인" 프레이밍, 7일 무료 체험 |
| 연간 첫해 프로모션 | 29,000 | 신년/새학기 시즌 한정 |
| 스트릭 프리즈 단품 | 1,100 / 3개 3,000 | 비구독자용 마이크로 결제, 절박한 순간의 전환 접점 |
| 코스메틱 팩 | 2,200~5,500 | Phase 2 |
| 챌린지 수수료 | 실패 보증금의 일부 + 성공 시 소액 운영비 | 챌린저스 모델 준용, 요율은 법무 검토 후 확정 |

- **연간 우선 노출**: 페이월 기본 선택을 연간으로. 습관 형성은 본질적으로 장기 여정이므로 "1년 뒤 달라진 나"라는 서사와 연간 결제가 정합.
- **지역 가격**: 글로벌 출시 시 구매력 기반 티어링 (스토어 가격 티어 활용).
- **AI 원가 방어**: AI 코치 무제한은 구독 전용으로 묶어 추론 비용을 구독 매출 안에서만 발생시킨다. 무료 유저에게는 주 1회 배치 생성 요약만 제공.

### 2.3 페이월 설계 원칙 (Pillar 반면교사 반영)

1. **타이밍 — 가치 체험 후 노출.** 첫 페이월은 온보딩 직후가 아니라 (a) 첫 습관 3일 연속 달성 직후, (b) 4번째 습관 추가 시도 시, (c) 첫 주간 리포트 열람 시. "잃기 싫은 것이 생긴 순간"에 보여준다.
2. **맥락별 페이월 변형.** 스트릭이 끊기기 직전엔 프리즈 중심, 통계 화면에선 인사이트 중심 카피. 단일 페이월보다 전환율이 유의미하게 높다는 것이 업계 통설 ([RevenueCat 페이월 가이드](https://www.revenuecat.com/blog/growth/guide-to-mobile-paywalls-subscription-apps/) 참조).
3. **탈출구 항상 제공.** 닫기 버튼을 숨기지 않는다. 하드 페이월식 강제는 단기 전환을 얻고 평점과 오가닉을 잃는 거래임이 Pillar 리뷰에서 실증됨.
4. **페이월 = 최우선 QA 대상.** 가격 로딩 실패·무한 루프 같은 결함은 매출 0가 아니라 유저 전체 이탈로 이어진다. 오프라인 캐시 가격, 로딩 타임아웃 시 폴백 UI, 온보딩→페이월 단방향 상태 머신을 필수 구현.
5. **체험 종료 고지.** 7일 체험 종료 D-1 알림을 앱이 먼저 보낸다. 기습 과금은 환불+1점 리뷰로 돌아온다. 신뢰가 곧 LTV다.

### 2.4 챌린지 보증금 모듈 (Phase 2 상세)

- **구조**: 유저가 "2주간 주 5회 아침 기상 인증"에 보증금(예: 1~5만원)을 건다. 달성 시 전액 환급 + 실패자 몰수금 풀에서 상금 배분. 앱은 운영 수수료를 취한다.
- **AI 결합 차별화**: 챌린지 기간 중 AI 코치가 실패 위험(체크인 시간 지연 패턴 등)을 감지하고 선제 개입 — "돈을 걸게 하고 방치"(기존 모델)가 아니라 "돈을 걸면 코치가 붙는다"로 포지셔닝.
- **리스크 관리**: 보증금 예치·정산은 PG 에스크로 구조로 처리하고, 몰수금 배분 방식은 사행성 이슈가 없도록 국내 법무 검토를 선행한다 (챌린저스 선례 연구). 인증 조작 방지는 사진 메타데이터 + 상호 검증 + AI 이상 탐지 3중으로.

## 3. 수익 시뮬레이션 가늠자 (업계 통상 범위 기반 가정치)

> 아래는 목표 설정용 가정치이며, 실측으로 대체해나갈 것.

| 지표 | 보수 | 기준 | 낙관 |
|---|---|---|---|
| 월 신규 설치 | 20,000 | 50,000 | 120,000 |
| 설치→체험 시작 | 6% | 9% | 12% |
| 체험→유료 전환 | 25% | 35% | 45% |
| 유료 12개월 유지율 | 30% | 40% | 50% |
| 연간 구독 ARPU | ₩33,000 | ₩36,000 | ₩39,000 |

- 기준 시나리오 대략치: 월 50,000 설치 × 9% × 35% ≈ 월 1,575명 신규 유료 → 첫해 말 유료 스톡 약 1.2~1.4만 명, 구독 매출 연 4~5억원 규모. 챌린지·코스메틱이 여기에 20~40% 가산.
- 민감도가 가장 큰 변수는 **체험→유료 전환**과 **12개월 유지율**이며, 둘 다 리텐션 설계(03 문서)가 좌우한다. 수익화의 병목은 가격이 아니라 리텐션이다.
