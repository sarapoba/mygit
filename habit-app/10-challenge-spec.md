# 10. 보증금 챌린지 명세 (Phase 2)

> 이 문서는 보증금 챌린지의 상품 구조·생명주기·정산 산식·인증/검증·어뷰징 대응·CS/법무 정책을 확정한다.
> 수익 모델 내 위치·가격 정합 → 02 문서 참조. Phase 2 검증 게이트(참가자 D30 +10%p, 완주율 ≥ 60%) → 04 문서 참조.
> AI 코치의 개입 로직·톤 상세 → 09 문서 참조. 소그룹·소셜 일반 설계 → 03 문서 참조. 챌린지 화면 플로우 → 11 문서 참조.

## 1. 설계 원칙 — 완주율이 수익보다 먼저다

1. **몰수 수익을 최적화하지 않는다.** 완주율이 낮으면 몰수 매출은 늘지만 재참가·평점·오가닉이 죽는다(04 게이트). 몰수 수수료는 결과이지 목표가 아니며, 상품 설계·AI 개입·난이도 가드레일은 전부 완주율 ≥ 60%를 향한다.
2. **"돈을 걸면 코치가 붙는다."** 기존 보증금 앱(챌린저스)과의 차별점은 방치가 아닌 개입이다(01 문서 §4). 챌린지 참가자는 구독 여부와 무관하게 챌린지 기간 중 AI 위험 개입을 받는다.
3. **보증금은 우리 돈이 아니다.** 예치금은 PG 에스크로에 두고 회사 운영 자금과 분리한다. 매출 인식은 운영비·몰수 수수료 확정분만.
4. **비난 없는 톤 유지.** 실패 확정 화면에도 죄책감 UI 금지 — "이번엔 아쉬웠지만 7일 중 5일을 해냈어요. 루티는 기억하고 있어요."

## 2. 상품 구조 3종

| 항목 | 무료 연습 챌린지 | 공식 챌린지 (운영 개설) | 소그룹 챌린지 (유저 개설) |
|---|---|---|---|
| 보증금 | 0원 | 10,000~50,000원 (1만원 단위) | 0원 또는 10,000~30,000원 |
| 기간 | 1주 고정 | 2주 기본, 최대 4주 | 1~4주 |
| 인증 빈도 | 주 3~5회 | 주 3~6회 (주 7회는 2분 버전급 극소 습관만 허용) | 주 3~6회 (주 7회 개설 불가) |
| 정원 | 제한 없음 | 최소 10명 ~ 최대 300명 (미달 시 자동 취소·전액 환불) | 2~10명 (03 문서 소그룹 규격) |
| 시작일 | 상시 (참가 즉시) | 코호트 고정 (매주 월요일 시작) | 개설자 지정 |
| 성공 보상 | XP + 이슬 + 프리즈 조각(수량 → 08 문서 §7.1) | 전액 환급 + 상금 (§4) | 전액 환급 + XP/이슬 (현금 상금 없음 — §7 담합 차단) |
| 참가 조건 | 없음 | 만 19세 이상 + 무료 연습 챌린지 1회 완주 | 만 19세 이상 (보증금형인 경우) |

- **무료 연습 챌린지 = 퍼널 상단 + 안전장치.** 인증 방식과 규칙을 돈 없이 학습시키고, 보증금 챌린지 첫 참가의 필수 관문으로 삼아 "규칙을 모르고 돈을 잃는" CS를 원천 차단한다.
- **첫 참가 보증금 상한 사다리**: 첫 보증금 챌린지는 10,000원까지만 → 1회 완주 후 30,000원 → 3회 완주 후 50,000원. 손실 경험보다 성공 경험을 먼저 쌓게 한다.
- 프리미엄 구독자 혜택은 수수료 50% 할인(§5). 챌린지 참가 자체는 무료 유저도 가능 — 챌린지는 구독의 대체재가 아니라 접점이다(02 문서 §2).

## 3. 챌린지 생명주기 (상태 머신)

```
[개설 DRAFT] → [모집 RECRUITING] → [진행 ACTIVE] → [이의신청 REVIEW(72h)] → [정산 SETTLED] → [회고 RETRO]
                     │                                                            
                     └─ 최소 인원 미달 / 개설 취소 → [취소 CANCELLED] (전액 환불)
```

| 상태 | 진입 조건 | 이 상태에서 일어나는 일 | 이탈 조건 |
|---|---|---|---|
| 개설 DRAFT | 운영 등록 또는 유저 개설(가드레일 검증 통과 — §11) | 규칙 확정: 인증 방식·빈도·시간대·보증금·정원. 게시 후 규칙 변경 불가 | 게시 → RECRUITING |
| 모집 RECRUITING | 시작 D-14~D-1 | 참가 = 보증금+운영비 결제 → PG 에스크로 예치. 시작 전 참가 취소 = 전액 환불 | 시작일 도래(최소 인원 충족) → ACTIVE / 미달 → CANCELLED |
| 진행 ACTIVE | 시작일 04:00 (로컬 하루 경계, → 06 문서 §2) | 인증 제출·3중 검증(§6)·AI 위험 개입(§9). 회차별 달성/실패/면제 확정 — 회차의 하루 경계도 04:00 준용 | 종료 익일 04:00 → REVIEW |
| 이의신청 REVIEW | 종료 직후 72시간 | 인증 판정 이의 접수, 증빙 심사(§8). 이 기간 중 정산 금지 | 이의 전건 종결 → SETTLED |
| 정산 SETTLED | REVIEW 종결 | 산식(§4)대로 환급·상금·수수료 확정, 영업일 5일 내 지급 | 지급 완료 → RETRO |
| 회고 RETRO | 정산 완료 | 회고 카드(달성률·최고 기록·루티 코멘트) + 다음 챌린지/66일 여정 추천 | — |

- 상태 전이는 단방향(Pillar 온보딩 루프 버그 반면교사 — 01 문서). REVIEW→ACTIVE 역행 없음. 이의 인용 시 판정값만 소급 수정 후 정산.

## 4. 보증금 자금 흐름과 정산 산식

### 4.1 자금 흐름

```
참가 결제 (보증금+운영비)
  → 보증금: PG 결제대금예치(에스크로) 계좌   [회사 매출 아님]
  → 운영비: 즉시 매출 인식
챌린지 종료 + REVIEW 종결
  → 정산 엔진 실행 (산식 4.2)
  → 환급분: 원결제수단 부분취소 우선, 불가 시 포인트 지급
  → 상금: 현금성 포인트 지급 (1,000원 이상 계좌 출금 가능 — 챌린저스 준용) [검토 필요: §10]
  → 몰수 수수료분: 이 시점에 매출 인식
```

### 4.2 환급·몰수·상금 산식 (국내 검증 선례 챌린저스 준용)

| 최종 달성률 | 처리 |
|---|---|
| 100% | 보증금 전액 환급 + 상금 풀 균등 배분 |
| 85% 이상 ~ 100% 미만 | 보증금 전액 환급 (상금 없음) |
| 85% 미만 | **환급 = 보증금 × 달성률** (100원 단위 올림), 잔여분 몰수 |

- 달성률 = 달성 회차 ÷ (총 회차 − 면제 회차). 부분 달성(2분 버전) 개념은 챌린지에선 미적용 — 인증 기준은 개설 시 고정(06 문서의 스트릭 규칙과 별개 시스템).
- 몰수 풀 배분: **상금 60% / 운영 수수료 40%.** 상금 비중을 높게 두는 이유는 원칙 1(완주율·평판 > 수익).
- **1인 상금 상한 = 본인 보증금의 20%** (사행성 방어 — §10). 상한 초과분은 운영 귀속 없이 차기 공식 챌린지 상금 풀로 이월.
- 소그룹 챌린지 몰수 풀: 현금 상금 배분 없음. 수수료 40% 제외 후 60%는 공식 챌린지 상금 풀로 이월(§7 시나리오 4 차단).

### 4.3 숫자 예시 — 공식 챌린지 "아침 6시 기상 인증"

조건: 2주 × 주 5회 = 총 10회, 보증금 30,000원, 참가 20명, 운영비 1인 1,500원(§5).

| 단계 | 계산 | 금액 |
|---|---|---|
| 총 예치 보증금 | 20명 × 30,000 | 600,000원 |
| 성공 15명 (100% 달성 12명 + 85~99% 3명) 환급 | 15 × 30,000 | 450,000원 |
| 실패 5명 비례 환급 | 달성률 70%×2명(21,000×2) + 50%×2명(15,000×2) + 20%×1명(6,000) | 78,000원 |
| **몰수 풀** | 150,000 − 78,000 | **72,000원** |
| 상금 풀 (60%) | 72,000 × 0.6 → 100% 달성 12명 균등 | 43,200원 (1인 3,600원 = 보증금의 12%, 상한 20% 이내) |
| 운영 수수료 (40%) | 72,000 × 0.4 | 28,800원 |
| 운영비 매출 | 프리미엄 8명 × 750 + 무료 12명 × 1,500 | 24,000원 |
| **회사 매출 합계** | 28,800 + 24,000 | **52,800원 (참가자 1인당 2,640원)** |

## 5. 운영 수수료 구조 (02 문서 §2.2 정합)

| 항목 | 확정안 | 비고 |
|---|---|---|
| 참가 운영비 | 보증금의 5% (최소 500원, 최대 2,000원), 참가 시 보증금과 별도 결제 | 02 문서 "성공 시 소액 운영비"의 구체화 — 성공해도 부담하는 유일한 비용 |
| 프리미엄 할인 | 참가 운영비 50% 할인 | 02 문서 무료/유료 경계표의 "챌린지 수수료 50% 할인" 대상 = 운영비 |
| 몰수 수수료 | 몰수 풀의 40% | 요율은 법무 검토 후 최종 확정(02 문서 단서 유지). 대안: 사행성 판단 보수적일 경우 상금 풀 축소·수수료 확대가 아니라 상금의 재화 전환으로 대응 |
| 무료 연습 챌린지 | 전면 무료 | CAC로 간주 — 보증금 퍼널 전환율로 정당화 |

## 6. 인증 방식 3종 × 3중 검증

### 6.1 인증 방식

| 방식 | 규칙 | 적용 예 |
|---|---|---|
| 사진 인증 | 앱 내 카메라 직촬만(갤러리 업로드 금지), 촬영 시각·챌린지명 워터마크 자동 합성, 개설 시 지정한 인증 시간대(예: 05:30~07:00) 내 제출만 유효 | 기상, 공부 책상, 식단 |
| 앱 내 자동 인증 | (a) 루트 습관 체크인 연동 — 위젯 원탭 체크가 곧 인증, 회차 귀속은 06 문서 §2의 04:00 경계를 그대로 따름(새벽 1시 체크는 전날 회차 — 체크인과 챌린지의 날짜 판정 분열 금지) (b) 인앱 타이머 — 지정 시간 이상 유지, 중도 이탈·화면 꺼짐 시 무효, 진행 중 무작위 1회 생존 확인 탭 (c) 걸음수 — HealthKit/Health Connect 읽기 | 명상, 집중 25분, 6,000보 |
| 워치 연동 | Apple Watch/갤럭시 워치 운동 세션 — HealthKit/Health Connect 경유, 수동 입력 기록은 인증 불인정 | 러닝, 근력 운동 |

### 6.2 3중 검증 (02 문서 §2.4 확정 구조의 상세)

| 층 | 검사 항목 | 판정 |
|---|---|---|
| 1층 메타데이터 (자동, 제출 즉시) | EXIF 촬영 시각·기기 모델 일치, 직촬 플래그, perceptual hash로 본인·타인 과거 이미지 중복 탐지, 워치 세션의 심박 변동 존재 여부 | 위반 시 제출 거부 + 사유 표시 (이 층에서 80%+ 걸러 상호 검증 부담 축소) |
| 2층 상호 검증 (사진 인증만) | 동일 챌린지 참가자 중 무작위 3인 배정(같은 소그룹·친구 관계 회피), 24시간 내 2/3 다수결. 판정 참여율은 검증자 신뢰도 점수에 반영 | 부결 시 제출자에게 즉시 통지 + 이의신청 안내. 판정 불성립(응답 2인 미만) 시 3층으로 |
| 3층 AI 이상 탐지 (비동기 배치) | 이미지 주제 분류(챌린지 내용 불일치), 제출 패턴(마감 직전 몰아 제출, 초 단위 연속 제출), 계정 간 이미지·기기·결제수단 유사도(다계정) | 이상 점수 상위 건 운영 검토 큐 → 어뷰징 확정 시 §7 제재 |

## 7. 어뷰징 시나리오와 대응

| # | 시나리오 | 탐지 | 대응 |
|---|---|---|---|
| 1 | 과거·갤러리 사진 재제출 | 직촬 강제 + EXIF 시각 + pHash 중복 | 해당 회차 무효, 반복 시 실격 |
| 2 | 무관한 사진으로 인증 (아무거나 촬영) | AI 주제 분류 + 상호 검증 부결 | 해당 회차 무효 |
| 3 | 마감 직전 몰아서 연속 제출 | 인증 시간대 제한 + 제출 간격 이상 탐지 | 초과분 무효 (1일 1회차 원칙) |
| 4 | 소그룹 다계정 담합 — 부계정 고의 실패로 몰수금 수취 | 기기·결제수단·이미지 유사도 교차 검사 | **구조적 차단: 소그룹은 현금 상금 배분 자체가 없음(§4.2)** + 다계정 확정 시 전 계정 실격 |
| 5 | 상호 검증 품앗이 (지인끼리 무조건 승인) | 무작위 배정 + 친구·소그룹 관계 회피 배정 + 3층 AI 샘플링 재검 | 검증자 신뢰도 하락 → 배정 제외, 반복 시 상금 수령 자격 정지 |
| 6 | 타이머 켜두고 방치 | 무작위 생존 확인 탭 무응답, 화면 꺼짐·앱 이탈 감지 | 해당 회차 무효 |
| 7 | 워치 수동 운동 기록 입력 | 수동 입력 소스 제외 + 심박 변동성 없는 세션 플래그 | 해당 회차 무효, 반복 시 워치 인증 자격 정지 |
| 8 | 진행 중 결제취소·차지백으로 보증금 회수 | PG 웹훅 실시간 감지 | 즉시 실격 처리 + 잔여 환급 0 + 재참가 제한 (약관 명시 — §10) |
| 9 | GPS 스푸핑 (장소 기반 인증) | 모의 위치 앱 탐지 | 위치는 보조 신호로만 사용, 단독 인증 수단으로 채택하지 않음 (원천 회피) |
| 10 | 미성년자·타인 명의 참가 | 결제 수단 본인 확인 + 만 19세 확인 | 참가 무효·전액 환불 (몰수 없음 — 법적 리스크 회피) |

제재 사다리: 회차 무효 → 챌린지 실격(환급 산식은 §4.2 그대로 적용, 어뷰징 회차만 실패 처리) → 챌린지 기능 이용 정지 30일 → 영구 정지. 어뷰징을 이유로 정상 회차분 환급까지 몰수하지 않는다(분쟁·법적 리스크 최소화).

## 8. CS·예외 정책

| 상황 | 처리 |

| 시작 전 참가 취소 | 보증금+운영비 전액 환불 (원결제수단 취소) |

## 9. AI 코치 결합 — 위험 감지 → 선제 개입

- 위험 신호: 인증 시각의 마감 방향 표류(3회 연속 지연), 2회 연속 실패, 달성률이 85% 환급선 −1회차 거리 진입.
- 개입 원칙: 챌린지는 인증 기준이 고정이라 "2분 버전 하향"(03 문서)을 쓸 수 없다. 대신 (a) 위험 회차 아침 선제 브리핑 (b) 전략 제안("기상 인증은 알람 옆에 폰 두는 분들의 성공률이 높아요") (c) 환급선 임박 시에만 손실 고지 1회 — "오늘 놓치면 환급 기준(85%) 아래로 내려가요. 오늘 하나면 지켜져요." **이 문구는 AI 생성이 아닌 챌린지 시스템 명의의 정적 템플릿으로 발송한다**(보증금이라는 금전 조건의 사실 고지 — 09 문서 §1·§8-7의 'AI 카피 손실 프레이밍 금지' 가드레일과 경로 분리).
- 중도 포기 버튼 클릭 시 만류 개입 1회(현재 달성률·환급 예상액 제시). 재클릭 시 즉시 확정 — 붙잡기 다크패턴 금지.
- 감지 모델·개입 카피·발송 빈도 상한 상세 → 09 문서 참조.

## 11. 완주율 ≥ 60% 원칙의 상품 설계 반영

| 장치 | 규칙 |
|---|---|
| 성공 기준 완충 | 100%가 아닌 85% 환급선 + 면제 제도(§8) — 완벽주의 붕괴 방지 철학(03 문서)의 챌린지 버전 |
| 난이도 가이드 | 참가 화면에 예상 난이도 표시: 본인의 해당 습관 최근 4주 체크인 달성률 기반. 달성률 50% 미만 습관으로 30,000원 이상 챌린지 참가 시 경고 + 낮은 보증금·낮은 빈도 대안 제시 (강제 차단은 하지 않음 — 자기결정 존중) |
| 무리한 개설 제한 (소그룹) | 주 7회 개설 불가(최대 주 6회 — 예비일 1일이 완주율을 만든다), 최대 4주, 1일 1회차, 보증금 상한 30,000원, 개설 조건 = 무료 연습 챌린지 1회 완주 |
| 보증금 사다리 | 첫 참가 10,000원 상한 → 완주 이력으로 상향(§2) — 첫 경험을 손실이 아닌 성공으로 |
| 상품 회수 기준 | 공식 챌린지 상품별 완주율 상시 모니터링, 2개 코호트 연속 완주율 50% 미만이면 판매 중단 후 빈도·기준 재설계 |
| 운영 대시보드 지표 | 완주율(1순위), 참가자 D30 대비 비참가자 +10%p(04 게이트), 재참가율, 이의신청률(품질 역지표), 몰수율(높을수록 경고 — 목표 아님) |
