# 05. 제품 정의서

> 이 문서는 루트(ROOT)의 컨셉·페르소나·가치 제안·유저 스토리·비기능 요구사항·비목표를 확정한다.
> 화면 플로우·와이어프레임 상세 → 11 문서 참조. 스트릭·프리즈·XP 산식 등 시스템 규칙 상세 → 06 문서 참조.

## 1. 컨셉 스테이트먼트

> **루트(ROOT)는 하루 2분의 원탭 체크인으로 새싹 '루티'를 나무로 키우면서, 하루쯤 놓쳐도 끊기지 않는 스트릭과 비난하지 않는 AI 코치가 66일 습관 형성을 완주시키는 앱이다.**

한 줄 포지셔닝(스토어 서브타이틀용): "혼내는 코치 말고, 같이 자라는 루티" — 갓생 피로감(자기계발 강박)과 완전 무계획 사이의 순한 톤 포지션 (→ 01 문서 §4).

## 3. 밸류 프로포지션 — Pains/Gains → 기능 매핑

| 페르소나 | Pain | 대응 기능 (Phase) | Gain |
|---|---|---|---|
| 서지우 | 하루 놓침 → 완벽주의 붕괴 → 전체 포기 | 프리즈 자동 소모 + "한 번은 사고" 회복 체크 + 복귀 시 죄책감 UI 금지 (P0~P1) | "한 번 실수해도 게임 오버가 아니다"는 안전감 |
| 서지우 | 의욕만 앞서 습관 과다 등록 → 과부하 | 무료 3개 제한 + 온보딩 2분 버전 강제 축소 (P0) | 작게 시작해 첫 주를 실제로 성공 |
| 서지우 | 혼자 하는 느낌, 피드백 없음 | 루티 성장·리액션 (P1), 소그룹 챌린지 (P2) | 매일 반겨주는 존재, 같이 하는 동료 |
| 김태윤 | 야근 변수로 계획 붕괴 | 부분 달성(2분 버전) 인정 + 체크인 시각 학습형 알림 (P0~P1) | 최악의 날에도 스트릭 방어 가능 |
| 김태윤 | 스트릭 리셋 트라우마 | 프리즈 사전 장착 + 스트릭 위험 알림(밤 9시) (P0) | 자산(스트릭)이 보험으로 보호됨 |
| 김태윤 | 기록만 쌓이고 행동 변화 없음 | AI 미루기 개입 + 주간 리포트 상관 인사이트 (P1), 보증금 챌린지 (P2) | 데이터가 코칭과 돈이라는 실행 압력으로 전환 |
| 박은정 | 시간 파편화 — 앱 열 틈도 없음 | 홈 위젯 원탭 체크(P0) + 잠금화면 위젯 빠른 진입(프리미엄, 원탭 체크 불가 — 06 §9) + 2분 버전 | 3초 안에 하루 기록 완료 |
| 박은정 | 경쟁·랭킹 강요 스트레스 | 리그 기본 off(opt-in), 비난 없는 코치 톤 (P1) | 평가받지 않는 자기만의 페이스 |
| 박은정 | 불가피한 결석(아이 간호 등)을 "실패" 취급 | 프리즈 + 회복 체크 + "루티가 기다렸어요" 복귀 연출 (P0~P1) | 삶의 변수가 죄책감으로 돌아오지 않음 |

## 5. 비기능 요구사항 (NFR)

### 5.1 오프라인 체크인 & 동기화

| 항목 | 요구사항 |
|---|---|
| 아키텍처 | **로컬 우선(local-first)**. 체크인·스트릭 계산·잔디·위젯은 기기 로컬 DB만으로 완전 동작. 서버는 동기화·백업·AI용 미러 |
| 오프라인 체크인 | 네트워크 없음 상태에서 체크인 즉시 로컬 기록+피드백. 차단 화면·에러 다이얼로그 금지, 상단 1줄 배너("오프라인 — 나중에 자동 저장돼요")만 표시 |
| 동기화 시점 | 재연결 시 백그라운드 자동 업로드. 실패 시 지수 백오프(최대 1시간 간격), 미동기화 데이터는 최소 30일 로컬 보존 |
| 충돌 규칙 | 체크인은 (habit_id, 날짜) 단위 **합집합 병합**(기록이 삭제를 이긴다 — 유저의 달성 기록은 절대 유실 금지). 습관 편집·설정은 last-write-wins(서버 수신 시각 기준) |
| 서버 권위 연산 | 프리즈 소모·회복 체크 판정·XP 지급은 동기화 시 서버가 최종 확정, 클라이언트는 낙관적 표시 후 보정. 판정 산식 자체 → 06 문서 |
| 게스트 데이터 | 게스트 모드 데이터는 기기 보관, 가입 시 전량 서버 이관. 앱 삭제 전 백업 미가입 유저에게 가입 유도 배너 1회 |

### 5.2 성능 목표

| 지표 | 목표 | 근거 |
|---|---|---|
| 콜드 스타트 → 체크 가능 화면 | ≤ 2.0초 (P75 기기 기준) | "3초 체크인" 약속의 전제 |
| 체크인 탭 → 피드백(햅틱+애니메이션 시작) | ≤ 100ms | 원탭 쾌감 = 코어 보상 |
| 체크인 → 위젯 반영 | ≤ 5초 | 위젯이 거짓말하면 신뢰 붕괴 |
| 페이월 가격 로딩 | ≤ 3초, 실패 시 캐시 가격 폴백 UI | Pillar 반면교사 (→ 01 문서 §2) |
| 크래시 프리 세션 | ≥ 99.8% | 페이월·온보딩 크래시는 P0 버그 |
| 첫 설치 용량 | ≤ 60MB (코스메틱 에셋은 온디맨드 다운로드) | 저가 안드로이드(서지우) 커버 |

### 5.3 접근성

- **WCAG 2.1 AA** 준수. 텍스트 대비 4.5:1 이상, 터치 타깃 최소 44×44pt.
- 시스템 폰트 크기 200%까지 레이아웃 깨짐 없이 지원 (35~45 타겟 필수 요건).
- 스크린리더(VoiceOver/TalkBack): 잔디 셀에 "6월 3일, 3개 중 2개 달성" 형식 라벨, 체크 버튼에 습관명+상태 라벨.
- 색상만으로 상태 구분 금지 — 잔디 농도에 체크 아이콘/숫자 병기, 프리즈 사용일은 색+눈송이 아이콘.
- 모션 감소 설정 시 루티 애니메이션을 정적 일러스트+텍스트 리액션으로 대체 (리액션 자체는 유지 — 보상 박탈 금지).

### 5.4 다크모드

- 시스템 설정 자동 연동 + 앱 내 수동 오버라이드(라이트/다크/시스템 3옵션).
- 다크 배경은 완전 검정(#000)이 아닌 짙은 남색 계열 — 루티·잔디 에셋의 대비 확보와 "밤의 정원" 무드 일관성. 대안: OLED 절전용 순흑 테마는 프리미엄 위젯 테마로 후순위.
- 루티·잔디·위젯 에셋은 라이트/다크 2세트 제작을 디자인 공수에 처음부터 산입. 위젯도 동일 규칙 적용.
