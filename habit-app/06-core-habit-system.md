# 06. 코어 습관 시스템 명세

> 습관 도메인 규칙의 **단일 진실 공급원(SSOT)**. 01~04의 확정 사항(프리즈, "한 번은 사고", 부분 달성, 66일 졸업 등)을 구현 가능한 수준의 규칙으로 상세화한다. 캐릭터(루티) 보상 연출은 → 08 문서, 알림·주간 퀘스트·리포트는 → 03 문서 참조.

## 1. 습관 타입 체계

내부 모델은 **주기 3종 × 측정 3종**의 조합이며, UI에는 아래 5종 프리셋으로 노출한다 (조합 전체를 노출하면 생성 마찰이 커짐).

| 타입 | 주기 | 측정 | 완전 달성 판정 | 예시 |
|---|---|---|---|---|
| 매일형 | 매일 | 단순 체크 | 하루 경계 내 체크 1회 | 아침 스트레칭 |
| 주N회형 | 주 N회 (N=1~6) | 단순 체크 | 주(월 04:00~차주 월 04:00) 안에 서로 다른 날 N일 체크 | 주 3회 러닝 |
| 요일지정형 | 지정 요일만 | 단순 체크 | 지정 요일의 하루 경계 내 체크 1회 | 월·수·금 헬스 |
| 수량형 | 매일(기본) 또는 요일지정 | 수량 누적 | 당일 누적 입력 합 ≥ 목표 수량 (분할 입력 합산) | 물 8잔 |
| 타이머형 | 매일(기본) 또는 요일지정 | 시간 누적 | 당일 타이머 누적 ≥ 목표 시간. 수동 기록도 허용(소급 규칙 준용) | 독서 30분 |

- 하루 1회만 달성 인정. 같은 날 중복 체크는 무시(XP 1회만).
- 요일지정형의 비지정일 체크는 "보너스 체크"로 기록만 남긴다 (잔디 표시 O, 스트릭 영향 X, XP 50%).
- 타이머형은 시작 시각 기준으로 날짜 귀속 (23:50 시작 → 그날 기록). 백그라운드 이탈 시 일시정지.

## 2. 하루 경계 — 04:00 리셋 (확정)

**하루 = 디바이스 로컬 시간 04:00 ~ 익일 04:00.** 스트릭 판정·잔디·프리즈 소모·위젯의 "오늘"이 모두 이 경계를 쓴다.

- 근거 1: 1차 타겟(20~35, 학생·주니어)의 취침이 자정 이후에 몰린다. 자정 리셋은 "자기 전 체크"(23시~새벽 1시)를 이틀로 쪼개 억울한 스트릭 끊김을 만들고, 이는 03의 이탈 경로("하루 놓침 → 붕괴") 시작점이 된다.
- 근거 2: 04:00은 활동 최저 시간대라 경계 통과 순간의 체크 혼선이 최소.
- 새벽 1시 체크는 **전날로 귀속**되며 UI에 반드시 명시: "어제(금)로 기록했어요."
- 대안: 유저 설정형 경계(02:00~06:00)는 경계 이동으로 소급 효과를 만드는 조작 여지 때문에 배제. Phase 3 글로벌 시 재검토.
- 저장은 UTC 타임스탬프 + 체크 순간의 타임존 오프셋. 판정은 체크 순간의 로컬 날짜 기준.

## 3. 체크인·언체크·소급 체크

| 규칙 | 내용 |
|---|---|
| 원탭 체크 | 앱·위젯 어디서든 1탭 = 완전 달성 기록. 낙관적 UI(200ms 내 반영) 후 서버 동기화 |
| 언체크 | 당일 하루 경계 전까지, **앱에서만** 가능(위젯 오탭 방지). XP·드랍 보상 회수. 드랍 재화를 이미 사용했으면 언체크 불가 |
| 소급 체크 | **직전 1일(어제)까지만** 허용. 앱 캘린더의 어제 칸에서만 진입. XP 50%, 가변 드랍 추첨 없음. 문구: "어제 하셨나요? 기록만 깜빡했다면 지금 남겨요." |
| 소급 vs 회복 구분 | 소급 체크 = "했는데 기록을 깜빡"(월 제한 없음) / 회복 체크 = "실제로 놓침"(월 1회, §4). 소급 체크가 성립하면 이미 소모된 프리즈는 반환 |

무제한 소급은 잔디·스트릭의 신뢰를 무너뜨리므로 1일로 고정. "자기 전 깜빡" 케이스의 대부분을 1일 소급이 흡수한다.

## 4. 스트릭 계산

### 4.1 자원 정의

| 자원 | 단위 | 지급/획득 | 보유 상한 | 소모 |
|---|---|---|---|---|
| 스트릭 프리즈 | 계정 공유 재화, 습관별 장착 토글(기본 ON) | 매월 1일 04:00 무료 1 / 프리미엄 4, 프리미엄은 광고 시청 +월 2 한도, 단품 구매(→ 02), 조각 5개 조립 | 무료 2 / 프리미엄 6 (초과 지급분 소멸) | 미스일 하루 경계에 자동 소모, 습관당 1개 |
| "한 번은 사고" 회복권 | **유저당 월 1회** (습관별이 아님 — 습관 3개면 월 3회가 되어 스트릭 가치가 희석됨) | 매월 1일 리셋, 이월 없음 | 1 | 회복 체크 수락 시 |
| 스트릭 부활 티켓 | 윈백 전용 (→ 03) | 7일 무접속 윈백 1회 | — | 끊긴 스트릭 복원 |

### 4.2 판정 알고리즘 (의사코드)

```
# 매일 04:00 배치 — 직전 날 D 판정
for habit in habits.filter(status == ACTIVE):
    if not is_due(habit, D):            # 요일지정 비지정일 / 주N회형(주 마감서 판정) / 일시정지 / 생성 전
        continue
    if achieved(habit, D):              # 완전 or 부분(2분) 달성
        habit.streak += 1
    else:
        misses.append(habit)

for habit in sort(misses, by=streak, desc):   # 스트릭 긴 습관부터 — 잃을 것이 큰 쪽 우선 보호
    if habit.freeze_on and user.freeze > 0:
        user.freeze -= 1                      # ① 프리즈 자동 소모
        mark(D, FROZEN)                       # 스트릭 유지, D는 +1 없음
    elif user.recovery_left > 0:
        habit.pending_until = boundary(D+2)   # ② 회복 대기 — D+1 하루 안에 기회
        mark(D, PENDING)
    else:
        habit.streak = 0                      # ③ 끊김 확정
        mark(D, MISSED)

# D+1 중 — 회복 대기 습관을 달성한 순간
on_achieve(habit) where habit.pending:
    show_card("어제는 사고였어요. 스트릭 이어갈까요?")   # 죄책감 문구 금지
    if accepted:
        user.recovery_left -= 1
        mark(D, RECOVERED)                    # 스트릭 유지, D는 +1 없음
# D+1 경계까지 미달성이면 그 시점에 streak = 0 확정
# 이틀 연속 미스는 무조건 끊김 — "미스 두 번부터가 진짜 끊김"(03)
```

### 4.3 주N회형의 스트릭

- 단위는 **주**. 표시도 "6주 연속". 일 단위 미스 개념이 없으므로 일일 프리즈 소모도 없다.
- 매주 월요일 04:00에 직전 주 판정: 달성일수 ≥ N → `week_streak += 1`. 미달 시 프리즈 1개 소모로 유지 → 없으면 회복권(다음 주 화요일 04:00 전까지 1회 달성 시 유지, 유저 월 1회 풀 공유) → 없으면 0.
- 주중 진행률은 "이번 주 2/3" 형태로 표시하고, 일요일 저녁 알림 접점은 → 03 문서 참조.

### 4.4 전체 데일리 스트릭

습관별 스트릭과 별도로, 그날 due 습관 중 **1개 이상 달성(부분 포함)** 이면 전체 스트릭 +1. 모든 due 습관이 프리즈/회복으로만 유지된 날은 전체 스트릭도 유지(+1 없음). 7/21/66일 마일스톤 연출은 습관별 스트릭 기준(→ 08).

## 5. 부분 달성 — "2분 버전"

- 모든 습관은 생성 시 **2분 버전을 필수 정의**한다 (미입력 시 자동 제안: 단순 체크형 "일단 시작만", 수량형 = 목표의 20%·최소 1단위, 타이머형 = 2분).
- 2분 버전 달성 = **스트릭·잔디·전체 완료 보너스 모두 "달성"으로 동일 인정.** 차이는 XP 50%와 잔디 연한 칸, 그리고 강도 기록(통계용)뿐이다. 0/1 이분법 제거가 목적이므로 판정에서 차별하지 않는다.
- 수량형·타이머형은 부분 기준 이상~목표 미만이면 자동으로 부분 달성 처리. 같은 날 목표까지 채우면 완전 달성으로 승격(XP 차액 지급).

## 6. 일시정지 · 보관 · 삭제 · 졸업

| 상태 | 규칙 |
|---|---|
| 일시정지 | 습관 단위, 3/7/14/30일 프리셋(최대 30일). 스트릭 동결, due 판정 제외, 잔디 회색 빗금, 위젯에서 숨김. 기간 중 체크하면 즉시 재개 + 정상 체크 처리. ※ 구독 3개월 일시정지(→ 02·03)와는 별개 개념 |
| 보관(아카이브) | 수동 보관 + 66일 졸업 시 자동 보관. 기록·역대 최고 스트릭 보존, **무료 3개 슬롯 미차지**. 재활성화 시 현재 스트릭 0에서 재시작(무료 유저는 슬롯 여유 필요) |
| 삭제 | 2단계 확인 → 30일 휴지통(복원 가능) → 영구 삭제. 이미 획득한 XP·재화는 회수하지 않음 |

| 12 | 오프라인 체크 후 이틀 뒤 동기화 | 로컬 타임스탬프 기준 소급 반영, 끊김 처리됐던 스트릭 재계산·복원 | 오프라인 유저 보호 |
| 13 | 습관 생성 당일 미체크 | 페널티 없음, 스트릭 0에서 시작. 다음 due일부터 판정 | 생성일은 계약 시작일 |

## 8. XP · 레벨

### 8.1 XP 획득표

| 행동 | XP | 비고 |
|---|---|---|
| 완전 달성 체크인 | +10 | 습관당 일 1회 |
| 부분 달성(2분 버전) | +5 | 같은 날 완전 달성 승격 시 +5 추가 |
| 소급 체크 | 해당 판정 XP의 50% | 가변 드랍 없음 |
| 오늘 due 습관 전부 달성 | +15 | 부분 달성 포함, 일 1회 |
| 회복 체크 수락 | +5 | 복귀를 보상 — 죄책감 대신 소액 보상 (03 철학) |
| 주간 퀘스트 완료 | XP 없음 | 보상은 프리즈 조각·이슬만(→ 03 문서 §4). XP는 체크인 계열 한정 — 레벨 페이싱(§8.3)의 66일 캘리브레이션 보호 |

### 8.2 가변 보너스 확률표 (체크인 1회당, 서버 추첨)

| 결과 | 확률 | 내용 |
|---|---|---|
| 루티 리액션만 | 60% | 연출 → 08 |
| XP +5 | 25% | 즉시 가산 |
| XP ×2 | 10% | 해당 체크인 XP 2배 |
| 코스메틱 재료(정식 명칭 '이슬' → 08 §7) ×1 | 4% | 30회 연속 미획득 시 다음 체크에서 확정 지급(천장) |
| 프리즈 조각 ×1 | 1% | 조각 5개 = 프리즈 1개. 조각 획득 월 5개 상한(무료 티어 월 1개 정기 지급 원칙 보호) |

### 8.3 레벨 공식

- 레벨 n → n+1 필요 XP = `100 + 40 × (n-1)`. 예: Lv1→2 100, Lv5→6 260, Lv10→11 460.
- 습관 3개 성실 사용 시 일 평균 약 40~50XP → 66일 시점 Lv 10 내외. 레벨은 루티 성장 단계와 매핑(→ 08).
- 언체크 시 XP 회수로 레벨이 내려갈 수 있으나, 레벨 다운 연출은 하지 않고 숫자만 조정(죄책감 UI 금지).

## 9. 위젯 명세

| 위젯 | 크기/형태 | 표시 요소 | 인터랙션 | 티어 |
|---|---|---|---|---|
| 홈 A "오늘" (기본) | 2×2 | 오늘 due 습관 최대 3개의 원형 체크 버튼, 전체 스트릭 일수, 루티 표정 아이콘(P1~ — Phase 0은 달성 링, → 08) | 버튼 탭 = 원탭 체크 | **무료** (기본 테마 1종) |
| 홈 B "잔디+오늘" | 4×2 | 최근 4주 잔디 28칸, 오늘 리스트 최대 5개, 프리즈 보유 수 | 체크 버튼 동일, 잔디 탭 = 통계 화면 딥링크 | 프리미엄 |
| 잠금화면 | iOS 원형·직사각 / Android 쇼트컷 | 다음 미완료 습관 1개 + 스트릭, 또는 오늘 달성 링(진행률) | 탭 = 앱 열고 해당 습관 포커스 (**잠금화면은 원탭 체크 불가** — 주머니 오탭 방지 + OS 제약) | 프리미엄 |

- 무료 = 홈 A 1종(02의 "기본 위젯 1종"). 홈 B·잠금화면·전체 테마가 프리미엄이며, 페이월 접점에서 프리뷰로 노출(→ 02).
- **원탭 체크 동작**: 탭 → 200ms 내 낙관적 완료 표시 + 햅틱 → 백그라운드 동기화. 단순 체크형·요일지정형은 즉시 완료, 수량형은 탭당 +1단위(목표 도달 시 완료 전환), 타이머형은 앱 타이머 화면 딥링크. 오프라인이면 로컬 큐에 적재 후 재시도. 언체크는 위젯 불가(§3).
- **갱신**: 체크인/언체크/프리즈 소모/하루 경계 04:00에 이벤트 즉시 갱신 + OS 정기 갱신 15분(iOS 타임라인 예약: 04:00·알림 시각, Android WorkManager). 04:00 강제 갱신 실패 대비 위젯 자체에 날짜 스탬프를 그려 "어제 상태" 오인을 방지.
- 위젯은 알림 의존 리스크(04 리스크 레지스터)의 대응 축이므로 Phase 0 필수 범위. 알림 문구·발송 전략은 → 03 문서 참조.
