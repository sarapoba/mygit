# 11. 정보 구조(IA) 및 화면 설계

> 전체 앱의 탭 구조·화면 인벤토리·핵심 화면 레이아웃·내비게이션 규칙·공통 컴포넌트의 SSOT.
> 온보딩 각본(S01~S14) → 07 문서, 위젯 명세 → 06 문서 §9, 루티 감정·연출 → 08 문서, 챌린지 산식·상태 머신 → 10 문서, 알림 문구·발송 전략 → 03 문서 §6, 접근성·다크모드 기준 수치 → 05 문서 §5.3~5.4.
> **와이어프레임 이미지는 본 문서 범위 외** — 텍스트 설계만 다루며, 비주얼은 디자인 핸드오프에서 본 문서를 원본으로 제작한다.

## 1. 하단 탭 구조 (확정)

**최종형(Phase 2+): 홈 · 기록 · 챌린지 · 루티 · 마이 5탭.**

| 탭 | 역할 | 탭 지위의 근거 |
|---|---|---|
| 1 홈 | 오늘의 체크인 — 일 단위 코어 루프 전체 | 세션의 90%가 여기서 시작·종료 |
| 2 기록 | 잔디·캘린더·주간/월간 리포트 — 주·월 훅 | "나를 알게 되는 보상"(03 §4)의 전용 공간, 페이월 접점 (c) |
| 3 챌린지 | 보증금·소그룹 챌린지 | Phase 2 매출·리텐션 축(02 §2.4) — 상시 노출 없이는 참가 퍼널이 죽는다 |
| 4 루티 | 캐릭터 성장·꾸미기·상점 | 애착 자산의 전용 무대 + 코스메틱 매출 동선(08 §6) |
| 5 마이 | 계정·알림·구독·프리즈 관리 | 구독 관리(일시정지 포함)의 신뢰 접점 |

- **AI 코치는 탭이 아니다.** 코치는 홈 상단 카드와 시트(HM-05)로 "찾아오는 존재"로 설계 — 탭으로 만들면 무료 유저(주 1회)에게 상시 빈 탭이 된다.
- **소셜 탭 없음.** 친구 습관 공유는 기록 탭 내부, 소그룹은 챌린지 탭 내부 (05 문서 Non-goal 4 정합).

### 1.1 Phase별 탭 노출 계획

| Phase | 탭 구성 | 3번 슬롯 | 규칙 |
|---|---|---|---|
| 0 | 홈 · 기록 · 마이 (3탭) | 미노출 | 루티·라이브러리·챌린지 미출시. 코드에는 5슬롯 뼈대를 예약해 추후 삽입 비용 최소화 |
| 1 | 홈 · 기록 · **라이브러리** · 루티 · 마이 (5탭) | 라이브러리(50종) | 5탭 근육기억을 여기서 확립. 라이브러리는 콜드스타트 자산(01 §2)이라 초기엔 탭 지위가 유효 |
| 2+ | 홈 · 기록 · **챌린지** · 루티 · 마이 | 챌린지로 교체 | 라이브러리는 탐색 빈도가 낮아지므로 습관 추가 플로우(HM-03)와 챌린지 탭 내 진입점으로 강등. 교체 후 2주간 챌린지 탭에 NEW 배지 |

대안: Phase 1부터 챌린지 탭을 "커밍순"으로 노출 — 기대감은 얻지만 빈 탭은 신뢰를 깎으므로 배제.

## 3. 핵심 5화면 상세 설계

### 3.1 HM-01 홈(오늘)

레이아웃(위→아래):

1. **상단 바**: 날짜(04:00 경계 기준 "오늘", 06 §2), 전체 스트릭 배지, 프리즈 칩(보유 수, 탭=MY-04).
2. **루티 미니 뷰포트** (높이 120pt, Phase 1 — P0은 달성 링+스트릭 배지만): 감정 상태 표시, 탭=리액션, 롱프레스=진행률 말풍선 (→ 08 §3~4). 오른쪽에 오늘 달성 링.
3. **AI 코치 카드** (Phase 1): 브리핑 1~2줄, 탭=HM-05. 스와이프로 오늘 하루 숨김 가능.
4. **오늘 습관 리스트**: 습관 카드(체크 버튼 56pt + 습관명 + 스트릭 일수). 정렬 = 미완료 due 우선 → 리마인더 시각순. 카드 탭=HM-02.
5. **주간 퀘스트 스트립** (Phase 1): 진행 바 1줄, 탭=RC-01.
6. **+ 습관 추가** 버튼: 무료 3개 도달 후 4번째 시도 시 PW-01(ctx=habit4) 소프트 노출.

| 상태 변형 | 표시 |
|---|---|
| HM-01·빈 (습관 0개) | 습관 리스트 대신 "루티가 첫 습관을 기다려요" + 추천 루틴 카드 3장(LB 연결). 빈 목록 금지(01 §2) |
| HM-01·위험 (21:00 이후 due 미완료) | 미완료 카드 상단 고정 + 배너 1개 "오늘 N일째예요. 2분이면 지킬 수 있어요". 배너는 '지킨다' 중심 보호 프레이밍 — 상실 어휘를 쓰는 손실 프레이밍은 밤 9시 알림 한 장면 전용(03 §6, §7-7). 루티는 '궁금' 상태(비난 아님) |
| HM-01·완료 (due 전부 달성) | 리스트 접힘 → 루티 '신남' 뷰포트 확대 + 한 줄 회고 입력(투자 단계, 선택) + 내일 첫 습관 예고 |

핵심 인터랙션: 체크 버튼 탭 → 100ms 내 햅틱+애니메이션(05 §5.2), XP·리액션·간헐 드랍 연출. 체크 버튼 롱프레스 → 옵션 시트(2분 버전으로 달성 / 편집). 회복 대기 습관은 카드에 "어제 것까지 살릴 수 있어요" 보조 버튼(판정 → 06 §4).

### 3.2 HM-02 체크인 상세

레이아웃(위→아래):

1. **헤더**: 습관명, 타입 태그, 스트릭 배지 + 다음 마일스톤 진행 바(7/21/66).
2. **오늘 액션 존**: 타입별 대형 액션 — 체크형=체크 버튼 72pt, 수량형=스테퍼, 타이머형=시작 버튼(→HM-04). 그 아래 "2분 버전으로 하기" 보조 버튼 상시 노출(부분 달성, 06 §5).
3. **습관별 잔디** 12주: 셀 탭 = 해당 일 기록 팝오버. 소급 체크 규칙 → 06 §3.
4. **기록 리스트**: 최근 체크·한 줄 회고.
5. **설정 진입**: 리마인더 시각, 2분 버전 정의, 일시정지/보관/졸업(→ 06 §6).

| 상태 변형 | 표시 |
|---|---|
| HM-02·완료 | 액션 존이 완료 상태로 전환. **언체크는 이 화면에서만 가능**(06 §3, 위젯 불가) |
| HM-02·회복대기 | 액션 존 위에 회복 체크 카드: "오늘 하면 어제까지 이어져요" (월 1회 룰 잔여 표시) |
| HM-02·프리즈 소모일 | 잔디·기록에 눈송이 표기, "프리즈가 지켜줬어요" 캡션 — 결손이 아니라 방어로 서술 |

### 3.3 RC-01 기록 홈 + RC-02 주간 리포트

**RC-01** (위→아래): 세그먼트(잔디/월 캘린더) → 전체 잔디 12주+(무료 기본 통계) → 습관 필터 칩 → 요약 스탯 타일 3개(이번 주 달성률·최장 스트릭·프리즈/회복 사용) → **심화 인사이트 잠금 카드**(상관 분석 미리보기 블러 + "프리미엄으로 보기" → PW-01 ctx=report).

**RC-02** (일요일 저녁 푸시 랜딩, 위→아래): 주간 달성률 헤더 → 최고 시간대 → 습관 간 상관 1건("운동한 날 공부 완료율 +30%") → 다음 주 퀘스트 제안 → 공유 버튼. **첫 열람 완료 시점에 PW-01(ctx=report) 1회 노출** — 리포트를 다 보여준 뒤에 노출한다(가치 체험 후 원칙, 02 §2.3).

| 상태 변형 | 표시 |
|---|---|
| RC-01·빈 (데이터 7일 미만) | 샘플 리포트 프리뷰 + "일주일이면 첫 리포트가 나와요" 카운트다운 |
| RC-02·저조 주 (달성률 30% 미만) | 등급·점수 표기 금지. "이번 주는 쉼표였어요" + AI 난이도 하향 제안 카드(03 §8) |
| RC-02·완벽 주 | 루티 축하 컷 + 다음 주 퀘스트 난이도 +1 제안 |

핵심 인터랙션: 잔디 셀 탭 = 일별 상세 팝오버(달성 목록·프리즈 여부). 미달성일 셀은 탭해도 "안 한 목록"을 나열하지 않고 그날의 달성만 보여준다.

### 3.4 PW-01 페이월 시트

**형태: 전체 화면이 아닌 하단 시트 모달.** 어느 접점에서든 동일 컴포넌트를 재사용하고 맥락 파라미터(ctx)로 헤더만 바꾼다.

## 6. 다크모드 · 접근성

기준 수치(WCAG 2.1 AA, 대비 4.5:1, 터치 44pt, 폰트 200%, 다크 팔레트)는 → 05 문서 §5.3~5.4가 원본. 본 문서는 화면 적용 규칙만 추가한다.

1. 폰트 200%에서 습관 카드는 2줄 래핑 허용, CheckButton 크기는 고정(레이아웃만 늘어남). 탭 바 라벨은 130%부터 아이콘 단독+툴팁.
2. 스크린리더 레이블 원칙 = **"명사, 상태, 행동"** 순: "물 마시기, 미완료, 이중 탭으로 체크" / "스트릭 47일, 프리즈로 보호됨". 잔디 셀 포맷은 05 §5.3 준용.
3. PW-01은 가격·기간·해지 조건을 하나의 접근성 노드로 묶어 전체 낭독 — 부분 낭독으로 인한 오인 결제 방지.
4. 모든 오버레이(OV-*)는 모션 감소 설정 시 정적 카드로 대체하되 보상 지급은 동일(05 §5.3).
5. 다크모드에서 잔디 농도 단계는 별도 팔레트로 재정의(라이트 농도의 단순 반전 금지 — 저농도 셀이 사라진다).
